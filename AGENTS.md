# Repository Guidelines

## Project Structure & Module Organization
- Notes by subject: `Math/`, `Chemistry/`, `Economics/`; chapters like `Math/1.Precalculus`, `Math/2.Limit`, `Math/3.Derivatives`.
- Daily logs: `Daily Notes/`. Media: `assets/` (images), `attachments/` (files). Layout/site: `_layouts/`, `docs/`.
- when insert images, use form '![alt text](path)'
- Keep original daily notes; when extracting topics, add backlinks to the source daily note.
- Foam/Obsidian friendly. Prefer wiki-links `[[...]]`; use card embeds `card![[...]]` when useful.

  - 章节内相对链接优先保持同目录短链；跨章节可用全路径 wiki-link（如 `[[Economics/3.Demand_Supply_Market_Equilibrium/market_equilibrium]]`）。

## Build, Test, and Development Commands
- No build required. Open in Obsidian or VS Code + Foam.
- Quick checks:
  - Find broken math spacing: `rg -n -P "\$\s|\s\$|\\\(\s|\s\\\)" Math`.
  - Find unresolved links: `rg -n "\[\[.*\]\]"` then verify paths.

## Python 虚拟环境 / Python Virtual Environment
- 用途 / Purpose：在仓库内使用专用 venv 运行绘图与轻量脚本，隔离依赖，避免污染系统环境。
- 位置 / Location：项目根目录 `.venv/`（不要提交到仓库）。
- 创建与激活 / Create & activate：
  - macOS/Linux：`python3 -m venv .venv && source .venv/bin/activate`
  - Windows：`python -m venv .venv && .venv\Scripts\activate`
- 安装绘图库 / Install plotting deps：`pip install -U pip matplotlib`。
- 生成图像的保存位置 / Where to save figures：
  - 日记/一次性插图：放入 `attachments/` 并在笔记中用 `![[attachments/xxx.png]]` 嵌入。
  - 学科笔记中可复用插图：优先放入 `assets/` 并使用相对路径引用。
- 使用与退出 / Use & deactivate：激活后直接运行 `python ...`；完成后 `deactivate` 退出。
- 复现提示 / Repro tip：若提示缺包，在已激活 venv 中执行 `pip install <package>` 即可。

## Coding Style & Naming Conventions
- Language: default contributions and examples in Simplified Chinese; notes are bilingual (每个段落/要点中英对照)。
- Filenames/folders: English only. Files use snake_case (e.g., `derivative_rules.md`); chapter folders prefixed `1.`, `2.`, … (avoid the word “chapter”).
- Headings: bilingual with slash, e.g., `# 极限 / Limits`.
- Math: inline `$...$`, display `$$...$$` or `\(...\)`/`\[...\]`; no spaces inside delimiters (e.g., `$y=f(x)$`).
- Links: use `[[Note/Path]]`. At page end keep only the markers:
  `[//begin]: # "Autogenerated link references for markdown compatibility"` … `[//end]: # "Autogenerated link references"` (do not hand-edit entries).
- Spacing / 间距：正文与自动生成的 wikilink 引用标记块之间保留一行空白；Between body content and the autogen wikilink reference markers block, leave exactly one blank line.

## Testing Guidelines
- No formal tests. Validate in Obsidian/Foam preview.
- For large edits, grep for math/links (see commands above) and spot-check a few files.

## Commit & Pull Request Guidelines
- Prefer editing existing files over adding new ones. Keep commits short and scoped (e.g., “数学笔记整理”, "fix math spacing"). Use concise, imperative summaries; bilingual is welcome.
- PRs include: what/why, scope (files/folders), screenshots for rendering fixes, and patterns used (e.g., trimmed `$...$` spaces).

## Security & Content Hygiene
- No secrets or private data. Use relative links; keep media in `assets/`/`attachments/`.
- Keep changes minimal and surgical; avoid renames that break wiki-links and existing references.

## Agent-Specific Instructions
- Default to Simplified Chinese responses unless the user requests otherwise.
- Use small, targeted patches; preserve structure, headings, and the link reference markers block.
- Maintain bilingual style per paragraph. Add wiki-links/backlinks; do not delete original content.
- For math cleanups, trim only delimiter-adjacent spaces; do not alter formula semantics.
