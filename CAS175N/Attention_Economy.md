# Attention Economy

## 1. 核心概念 / Core Concept

注意力经济是指将注意力作为稀缺资源进行买卖的经济模式。  
Attention economy refers to the economic model where attention is treated as a scarce resource to be bought and sold.

## 2. 主要特征 / Key Characteristics

- **消费化 / Consumerization:** Turn US into consumers
- **广告 / Advertising:** 通过广告获取注意力 / Capture attention through advertising
- **监控 / Surveillance:** 数据收集和用户行为追踪 / Data collection and user behavior tracking
- **商品化 / Commodification:** turns attention into commodity
- **获取+保持 / Capture+Hold:** grab+hold our attention

## 3. 影响 / Impacts

注意力经济改变了：
- 媒体消费模式 / Media consumption patterns
- 信息获取方式 / Information acquisition methods
- 社会互动模式 / Social interaction patterns
