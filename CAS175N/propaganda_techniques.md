# 宣传的定义与技巧 / Propaganda Definition & Techniques

宣传是有意、系统地塑造感知、改变认知并引导行为以实现传播者目标的沟通实践。 / Propaganda is the deliberate, systematic attempt to shape perceptions, manipulate cognitions, and direct behavior to achieve the propagandist’s aims.

## 核心要素 / Key Elements

- 有意性与系统性 / Intentional and systematic
- 明确目标与受众 / Clear goals and audiences
- 通过感知与认知影响行为 / Influence behavior via perceptions and cognitions

## 常见技巧 / Common Techniques

1. 背书与推荐 / Endorsements & testimonials
2. 随大流（从众）/ Bandwagon
3. 个人诉求 / Personal appeals
4. 华丽空泛 / Glittering generalities
5. 人身攻击（污名化）/ Name calling
6. 诱导性用词（带情绪词）/ Loaded words
7. 选择性陈述（堆牌）/ Card stacking
8. 误导性数字 / Misleading numbers
9. 刻板印象 / Stereotyping
10. 平民化诉求 / Plain folks appeals
