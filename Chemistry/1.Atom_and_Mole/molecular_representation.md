# 4. 分子表示法 / Molecular Representation

## 分子式 / Molecular Formula

### 定义 / Definition

分子式表示分子中各元素的种类和数量。

Molecular formula shows the types and numbers of atoms in a molecule.

### 例子 / Examples

- **水分子** / Water molecule: H₂O
  - 含有2个氢原子和1个氧原子
  - Contains 2 hydrogen atoms and 1 oxygen atom

- **二氧化碳** / Carbon dioxide: CO₂
  - 含有1个碳原子和2个氧原子
  - Contains 1 carbon atom and 2 oxygen atoms

- **甲烷** / Methane: CH₄
  - 含有1个碳原子和4个氢原子
  - Contains 1 carbon atom and 4 hydrogen atoms

## 结构式 / Structural Formula

### 定义 / Definition

结构式表示原子在分子中的连接方式。

Structural formula shows how atoms are connected in a molecule.

### 表示方法 / Representation Methods

1. **简化结构式** / Condensed structural formula
   - 例如：CH₃-CH₂-OH（乙醇）
   - Example: CH₃-CH₂-OH (ethanol)

2. **线角式** / Line-angle formula
   - 用线段表示化学键
   - Uses line segments to represent chemical bonds

3. **路易斯结构式** / Lewis structure
   - 显示价电子的分布
   - Shows distribution of valence electrons

## 分子几何 / Molecular Geometry

### 基本几何形状 / Basic Geometric Shapes

1. **线型** / Linear
   - 例如：CO₂, BeF₂
   - Example: CO₂, BeF₂

2. **三角形** / Trigonal planar
   - 例如：BF₃
   - Example: BF₃

3. **四面体** / Tetrahedral
   - 例如：CH₄, NH₄⁺
   - Example: CH₄, NH₄⁺

4. **三角锥** / Trigonal pyramidal
   - 例如：NH₃
   - Example: NH₃

## 分子式与摩尔质量 / Molecular Formula and Molar Mass

### 计算分子摩尔质量 / Calculating Molecular Molar Mass

分子的摩尔质量 = Σ(原子摩尔质量 × 原子个数)

Molecular molar mass = Σ(atomic molar mass × number of atoms)

### 例子 / Example

**水分子 H₂O:**
- H: 1.01 g/mol × 2 = 2.02 g/mol
- O: 16.00 g/mol × 1 = 16.00 g/mol
- 总摩尔质量 = 18.02 g/mol
- Total molar mass = 18.02 g/mol
