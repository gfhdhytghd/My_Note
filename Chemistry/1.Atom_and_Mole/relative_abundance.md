# 3. 相对丰度 / Relative Abundances

> 本笔记整理自 [[Daily Notes/2025-08-27|2025-08-27 日记]]

## 什么是相对丰度？ / What is Relative Abundances?

相对丰度是指元素的不同同位素在自然界中的存在百分比。

Relative abundances refer to the percentages of different isotopes of an element found in nature.

## 计算平均原子质量 / Calculating Average Atomic Mass

用于计算平均原子质量：平均原子质量 = Σ(同位素质量 × 相对丰度)

Used to calculate average atomic mass: Average atomic mass = Σ(isotope mass × relative abundance)

### 计算公式 / Formula

$$\text{平均原子质量} = \sum_{i} (\text{同位素质量}_i \times \text{相对丰度}_i)$$

$$\text{Average atomic mass} = \sum_{i} (\text{isotope mass}_i \times \text{relative abundance}_i)$$

## 实例计算 / Example Calculation

### 氯元素 / Chlorine Element

氯有两种主要同位素：
Chlorine has two major isotopes:

- 氯-35: 相对丰度 75.8%, 质量 34.97 AMU
- 氯-37: 相对丰度 24.2%, 质量 36.97 AMU

**计算过程 / Calculation:**
- 平均原子质量 = (34.97 × 0.758) + (36.97 × 0.242)
- = 26.51 + 8.95
- = 35.46 AMU

### 其他例子 / Other Examples

**碳元素 / Carbon Element:**
- 碳-12: 98.93%, 12.00 AMU
- 碳-13: 1.07%, 13.00 AMU
- 平均原子质量 = (12.00 × 0.9893) + (13.00 × 0.0107) = 12.01 AMU

## 应用意义 / Applications

1. **元素周期表中的原子质量** / Atomic masses in periodic table
   - 周期表中列出的原子质量是平均值
   - The atomic masses listed in the periodic table are average values

2. **化学计算** / Chemical calculations
   - 用于摩尔质量的计算
   - Used for molar mass calculations

3. **同位素分析** / Isotope analysis
   - 确定样品中同位素的组成
   - Determine isotopic composition of samples
