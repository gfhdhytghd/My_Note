# 元素周期表 / Periodic Table

## 1. 周期表概述 / Overview

元素周期表是化学中最重要的工具之一，它按照原子序数（质子数）排列所有已知元素。

The periodic table is one of the most important tools in chemistry, organizing all known elements by atomic number (number of protons).

### 基本结构 / Basic Structure
- **周期 / Periods**: 水平行，表示电子层数
- **族 / Groups**: 垂直列，表示价电子数
- **主族 / Main Groups**: 1-2族和13-18族
- **过渡金属 / Transition Metals**: 3-12族

## 2. 周期性规律 / Periodic Trends

### 2.1 原子半径 / Atomic Radius
- **同周期**: 从左到右递减
- **同族**: 从上到下递增

### 2.2 电离能 / Ionization Energy
- **同周期**: 从左到右递增
- **同族**: 从上到下递减

### 2.3 电负性 / Electronegativity
- **同周期**: 从左到右递增
- **同族**: 从上到下递减

## 3. 主要元素族 / Major Element Groups

### 3.1 碱金属 / Alkali Metals (第1族)
- 最外层1个电子
- 高反应性
- 常见: Li, Na, K, Rb, Cs, Fr

### 3.2 碱土金属 / Alkaline Earth Metals (第2族)
- 最外层2个电子
- 中等反应性
- 常见: Be, Mg, Ca, Sr, Ba, Ra

### 3.3 卤素 / Halogens (第17族)
- 最外层7个电子
- 高电负性
- 常见: F, Cl, Br, I, At

### 3.4 惰性气体 / Noble Gases (第18族)
- 最外层8个电子（He为2个）
- 化学惰性
- 常见: He, Ne, Ar, Kr, Xe, Rn

## 4. 过渡金属 / Transition Metals

### 4.1 第一过渡系 / First Transition Series
- Sc, Ti, V, Cr, Mn, Fe, Co, Ni, Cu, Zn

### 4.2 镧系和锕系 / Lanthanides and Actinides
- 镧系: 57-71号元素
- 锕系: 89-103号元素

## 5. 金属性分类 / Metallic Classification

### 5.1 金属 / Metals
- 导电性良好
- 延展性
- 金属光泽

### 5.2 非金属 / Nonmetals
- 导电性差
- 脆性
- 无金属光泽

### 5.3 类金属 / Metalloids
- 介于金属和非金属之间
- 半导体性质

## 6. 重要应用 / Important Applications

### 6.1 预测性质 / Predicting Properties
- 根据位置预测化学性质
- 理解反应趋势

### 6.2 化学键 / Chemical Bonding
- 离子键: 金属与非金属
- 共价键: 非金属之间
