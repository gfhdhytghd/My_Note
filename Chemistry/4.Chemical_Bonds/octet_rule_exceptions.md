# 八隅体规则的例外 / Exceptions to the Octet Rule

**基本概念 / Basic Concept**  
八隅体规则指出原子倾向于获得8个价电子以达到稳定状态，但存在多种例外情况。  
The octet rule states that atoms tend to gain 8 valence electrons for stability, but there are several exceptions.

## 1. 奇数个电子 / Odd Number of Electrons

- 有些分子或离子总价电子数是奇数，因此无法让所有原子都凑齐8个电子。  
  Some molecules or ions have an odd total number of valence electrons, so not all atoms can reach an octet.
- 这种情况称为自由基。  
  Such species are called free radicals.
- 例子：$NO$（一氧化氮），$ClO_2$（二氧化氯）。  
  Examples: $NO$ (nitric oxide), $ClO_2$ (chlorine dioxide).

## 2. 中心原子少于八隅体 / Less than an Octet on the Central Atom

- 某些小原子因为价电子数有限，无法达到8个电子。  
  Some small atoms cannot reach 8 electrons due to limited valence electrons.
- 常见元素：$B$（硼）、$Be$（铍）。  
  Typical elements: $B$ (boron), $Be$ (beryllium).
- 例子：$BF_3$（三氟化硼，$B$只有6个价电子），$BeCl_2$（氯化铍，$Be$只有4个价电子）。  
  Examples: $BF_3$ (boron has 6 valence electrons), $BeCl_2$ (beryllium has 4 valence electrons).

## 3. 中心原子超过八隅体 / Expanded Octet on the Central Atom

- 第三周期及之后的主族元素可使用$d$轨道，容纳超过8个电子。  
  Main-group elements from period 3 onward can use $d$ orbitals to accommodate more than 8 electrons.
- 例子：$PCl_5$（$P$有10个电子），$SF_6$（$S$有12个电子）。  
  Examples: $PCl_5$ ($P$ has 10 electrons), $SF_6$ ($S$ has 12 electrons).

## 4. 立体数 / Steric Number (SN)

**定义 / Definition**  
立体数是中心原子周围的电子域总数（$=$ 成键$\sigma$键数 $+$ 孤对电子数）。  
Steric number is the total number of electron domains around the central atom ($=$ number of $\sigma$ bonds $+$ number of lone pairs).

**用途 / Use**  
用于判定电子域几何与分子几何（VSEPR框架）。  
Determines electron-domain geometry and molecular geometry (VSEPR framework).

**快速例子 / Quick Examples**  
- $SN=2$ → 线形（linear）：如$BeCl_2$（中心$Be$：2个成键对，0孤对）。  
  $SN=2$ → linear: e.g., $BeCl_2$ (central $Be$: 2 bonding pairs, 0 lone pairs).
- $SN=3$ → 平面三角形（trigonal planar）：如$BF_3$。  
  $SN=3$ → trigonal planar: e.g., $BF_3$.
- $SN=4$ → 正四面体（tetrahedral）：如$CH_4$。  
  $SN=4$ → tetrahedral: e.g., $CH_4$.
- $SN=5$ → 三角双锥（trigonal bipyramidal）：如$PCl_5$。  
  $SN=5$ → trigonal bipyramidal: e.g., $PCl_5$.
- $SN=6$ → 正八面体（octahedral）：如$SF_6$。  
  $SN=6$ → octahedral: e.g., $SF_6$.

## 5. 电子域 / Electron Domain

**定义 / Definition**  
围绕中心原子的一个电子密度区域；每个$\sigma$成键对或一对孤对电子各计作1个电子域。  
A region of electron density around the central atom; each $\sigma$ bond pair or a lone pair counts as one domain.

**重要特点 / Key Features**  
- 多重键（双键、三键）在几何判定中视作1个电子域。  
  Multiple bonds (double/triple) count as one electron domain for geometry determination.
- 孤对电子占据空间更大，会使键角相对无孤对的同$SN$架构减小。  
  Lone pairs occupy more space, reducing bond angles relative to the same $SN$ without lone pairs.

**典型示例（$SN=4$）/ Typical Examples (SN=4)**  
- 0孤对：正四面体（$CH_4$）。  
  0 lone pairs: tetrahedral ($CH_4$).
- 1孤对：三角锥（$NH_3$）。  
  1 lone pair: trigonal pyramidal ($NH_3$).
- 2孤对：折线形（$H_2O$）。  
  2 lone pairs: bent ($H_2O$).

**小结 / Summary**  
八隅体规则有三类常见例外：  
There are three common exceptions to the octet rule:
1. 奇数电子（自由基）。  
   Odd-electron species (free radicals).
2. 不足八隅体（如$B$、$Be$）。  
   Incomplete octet (e.g., $B$, $Be$).
3. 扩展八隅体（第三周期及之后）。  
   Expanded octet (period 3 and beyond).

画[[lewis_structures]]时若电子数对不上，通常是遇到以上情形。  
When drawing [[lewis_structures]], mismatched electron counts usually indicate one of the cases above.
