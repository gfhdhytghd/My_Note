# 2. 分类总览 / Taxonomy Overview

- **烃类（C–C/C–H）/ Hydrocarbons (C–C/C–H):** 烷、烯、炔、芳香 / alkanes, alkenes, alkynes, arenes.
- **含杂原子 / Heteroatom-bearing:** 卤代烃、醇、酚、醚、环氧、胺、硝基、腈、硫醇、硫醚 / haloalkanes, alcohols, phenols, ethers, epoxides, amines, nitro, nitriles, thiols, thioethers.
- **羰基衍生物 / Carbonyl-derived:** 醛、酮、羧酸、酯、酸酐、酰氯、酰胺 / aldehydes, ketones, carboxylic acids, esters, anhydrides, acyl chlorides, amides.
