# 有机物命名：烷/烯/炔 / IUPAC Nomenclature: Alkanes/Alkenes/Alkynes
 - 目标/Scope：系统梳理烷烃、烯烃、炔烃的IUPAC命名<br>Systematically cover IUPAC names for alkanes, alkenes, and alkynes.
 - 相关/Related：见键性质与立体概念[[Chemistry/4.Chemical_Bonds/bond_properties]]<br>See also bonding and stereochemistry [[Chemistry/4.Chemical_Bonds/bond_properties]].

## 命名总则 / General Rules
- 最长主链/Longest parent chain：选择包含最多重键（C=C/C≡C）的最长链<br>Choose the longest chain containing the maximum number of multiple bonds.
- 编号/Numbering：使重键位置数值尽可能小（比较序列而非仅首个）<br>Number to give the lowest possible set of locants to multiple bonds (compare the whole set).
- 优先级/Priority（烯 vs 炔）：若最低序列并列，双键优先得更小序号<br>If a tie remains, double bonds get the lower locant than triple bonds.
- 主名/Parent name：烷“ane”、烯“ene”、炔“yne”；多重键用“diene/triene…、diyne/…”<br>Use “ane/ene/yne”; use “di-, tri-” for multiple bonds (e.g., diene, diyne).
- 组合/Combination（烯炔）：同时存在用“en…yne”并按编号顺序列出<br>With both, use “en…yne” and list in numeric order.
- 取代基/Substituents：以烷基、卤素等作前缀，给出位置与数量<br>Use alkyl/halo prefixes with locants and multiplicative prefixes.
- 排序/Alphabetical order：按字母序排列前缀，忽略 di/tri/tetra；“sec-/tert-”不参与排序，“iso-/neo-”参与<br>Order alphabetically ignoring di/tri/tetra; ignore sec-/tert-, but count iso-/neo-.
- 标点/Punctuation：位置号用逗号分隔，位置与词根用连字符，无空格<br>Use commas between numbers, hyphens between numbers and words, no spaces.

## 烷烃 / Alkanes
- 定义/Definition：饱和链烃（无C=C/C≡C）<br>Saturated chain hydrocarbons (no C=C/C≡C).
- 主链与取代/Parent and substituents：先定最长主链，再命名取代基并以最小定位号<br>Determine the longest chain, then name substituents with the lowest locants.
- 例/Example：`CH3-CH(CH3)-CH2-CH2-CH3` → 2-甲基戊烷<br>2-methylpentane.

## 烯烃 / Alkenes
- 主链包含双键/Parent includes C=C：链名改后缀为“ene”<br>Parent suffix becomes “ene”.
- 编号优先/Numbering priority：确保双键定位号最小<br>Ensure the smallest possible locant for the double bond.
- 多双键/Multiple double bonds：如“diene、triene”，位置全列出<br>Use diene/triene with all locants listed.
- 构型/Stereo：必要时标注E/Z（依据CIP规则）<br>Specify E/Z when needed (per CIP rules).
- 例/Example：`CH3-CH(CH3)-CH2-CH=CH2` → 4-甲基戊-1-烯<br>4-methylpent-1-ene.

## 炔烃 / Alkynes
- 主链包含三键/Parent includes C≡C：链名改后缀为“yne”<br>Parent suffix becomes “yne”.
- 编号优先/Numbering priority：三键得到尽可能小定位号（若与双键并列，双键优先更小号）<br>Triple bond gets the lowest possible locant (in a tie with double bonds, double gets the lower number).
- 多三键/Multiple triple bonds：如“diyne、triyne”，位置全列出<br>Use diyne/triyne with all locants.
- 例/Example：`CH3-C≡C-CH2-CH3` → 戊-2-炔<br>pent-2-yne.

## 烯炔并存 / Enynes
- 组合形式/Combined form：名称中按编号升序写“en-…-yn-”<br>List “en-…-yn-” in ascending locant order.
- 例/Example：`CH≡C-CH2-CH=CH-CH3` → 按序：己-4-烯-1-炔（若可并列，双键优先较小号）<br>hex-4-en-1-yne (double bond gets the lower number in tie).

## 取代基与次序 / Substituents and Ordering
- 位置与数量/Locants and multiplicity：如 3,4-二甲基；多种取代基用字母序<br>Use 3,4-dimethyl; order different substituents alphabetically.
- 字母序细则/Alphabetizing notes：忽略 di/tri/tetra 等；“sec-/tert-”忽略，“iso-/neo-”计入<br>Ignore di/tri/tetra; ignore sec-/tert-; count iso-/neo-.
- 常见前缀/Common prefixes：氟/氯/溴/碘 → fluoro/chloro/bromo/iodo<br>Apply halo prefixes as needed.

## 具名示例 / Worked Examples
- `CH3-CH2-CH(CH3)-CH2-CH3` → 3-甲基戊烷<br>3-methylpentane.
- `CH3-CH(CH3)-CH(CH3)-CH3` → 2,3-二甲基丁烷<br>2,3-dimethylbutane.
- `CH3-CH2-CH=CH-CH3` → 戊-2-烯（或2-戊烯）<br>pent-2-ene (or 2-pentene).
- `CH3-CH=CH-CH2-CH(CH3)-CH3` → 2-甲基己-3-烯（若需标注 E/Z）<br>2-methylhex-3-ene (add E/Z if needed).
- `CH3-CH2-C≡C-CH3` → 戊-2-炔<br>pent-2-yne.
- `CH2=CH-CH2-C≡CH` → 戊-4-烯-1-炔<br>pent-4-en-1-yne.

## 易错点 / Common Pitfalls
- 只看第一定位号是错的；应比较完整定位号序列。<br>Comparing only the first locant is wrong; compare the full locant set.
- 忽略字母序规则会导致排序错误。<br>Ignoring alphabetizing rules leads to wrong substituent order.
- 遗漏 E/Z 或重复键个数前缀（diene/diyne）。<br>Forgetting E/Z or multiplicative prefixes is common.

## 练习 / Practice
- 命名：`(CH3)2CH-CH2-CH=CH2`；`CH3-C≡C-CH(CH3)-CH3`；`CH2=CH-CH=CH-CH3`；`CH≡C-CH=CH-CH3`。<br>Naming: `(CH3)2CH-CH2-CH=CH2`; `CH3-C≡C-CH(CH3)-CH3`; `CH2=CH-CH=CH-CH3`; `CH≡C-CH=CH-CH3`.
- 画结构：命名→结构：3-乙基-2-甲基己烷；己-2,4-二烯；戊-1-炔；己-3-烯-1-炔。<br>Draw structures: 3-ethyl-2-methylhexane; hex-2,4-diene; pent-1-yne; hex-3-en-1-yne.
