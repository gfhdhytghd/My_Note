## 课程内容与目标 / Description and Objectives

课程围绕数据结构、面向对象与函数式 Python、抽象数据类型、算法效率、搜索与排序、基础复杂度理论和程序设计语言基础展开。/ The course covers data structures, object-oriented and functional Python, abstract data types, algorithm efficiency, searching and sorting, elementary complexity theory, and programming-language concepts.

完成课程后，应能设计并实现标准风格的计算解决方案、调试和预测程序行为、分析 Big-O 效率，并构建模块化可复用的软件组件。/ Students should be able to design and implement solutions, debug and predict program behavior, analyze Big-O efficiency, and build modular reusable software components.

## 作业与考试 / Assignments and Exams

- Labs：90% 为功能/测试通过，10% 为课程概念使用；不遵循题目指定限制（例如 `break`、`continue`、全局变量）可能导致严重扣分。
- Homework：60% 测试正确性，40% 代码清晰度与设计；必须自行编写代码、使用描述性变量名、写注释并通过 starter code doctests。
- 作业通常周五 11:59 PM（ET）截止。Labs 和 homework 各有一次 **24 小时无扣分 grace period**；不适用于 checkpoints、quizzes 或 recitation activities。
- 所有考试均为纸笔 coding questions，closed notes（教师在试卷提供的资料除外）；禁止手机、Python IDE、耳机。
- 缺考需在 24 小时内联系教师并提供合格证明；旅行、准备不足等不是可接受理由。
