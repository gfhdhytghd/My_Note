# 通过 Canvas 使用 MyLab Math / Access MyLab Math from Canvas

> Canvas 来源 / Source：<https://psu.instructure.com/courses/2487353/pages/important-access-mylab-math-from-canvas?module_item_id=49060177>
>
> 类型 / Type：Course Information 网页；采集日期 / captured 2026-08-25。

## 访问要求 / Access requirement

整个学期均必须通过 Canvas 进入 Pearson 内容。Throughout the semester, Pearson content must be accessed through Canvas.

## 首次关联步骤 / Initial linking steps

1. 在左侧导航选择 MyLab and Mastering 或 Pearson Access。Select MyLab and Mastering or Pearson Access in the left navigation.
2. 选择 `Open Pearson`。Select `Open Pearson`.
3. 同意 Pearson 隐私政策或认证请求。Accept Pearson privacy-policy or authentication prompts.
4. 登录 Pearson，或创建 Pearson 账号。Sign in to Pearson or create an account.
5. 选择 `Link Accounts`；如出现确认页，选择 `Continue`。Select `Link Accounts`, then `Continue` if prompted.
6. 选择访问方式：预购 access code、信用卡、PayPal 或 14 天免费临时访问。Choose an option such as pre-purchased access code, credit card, PayPal, or 14-day temporary access.
7. Pearson 课程内容出现后，回到浏览器中的 Canvas 标签页或窗口。After Pearson content appears, return to Canvas in the browser.

## 临时访问与支持 / Temporary access and support

临时访问期间，进入 Pearson 时会定期显示付费选项，也可从临时访问确认或提醒邮件中升级。Payment options appear periodically during temporary access and can also be opened from the confirmation/reminder email.
