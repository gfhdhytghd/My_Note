## 1. 多项式分式极限最高次项法则 / Leading Term Rule for Rational Function Limits

**定理（中文）：**  
当 $x \to \infty$ 或 $x \to -\infty$ 时，多项式分式 $\frac{P(x)}{Q(x)}$ 的极限，只需比较分子分母的最高次项。  
- 若 $\deg P < \deg Q$，极限为 $0$。  
- 若 $\deg P = \deg Q$，极限为最高次项系数之比。  
- 若 $\deg P > \deg Q$，极限为无穷大（正或负，视系数符号而定）。

**Theorem (English):**  
As $x \to \infty$ or $x \to -\infty$, for a rational function $\frac{P(x)}{Q(x)}$, only the leading terms matter:  
- If $\deg P < \deg Q$, the limit is $0$.  
- If $\deg P = \deg Q$, the limit is the ratio of leading coefficients.  
- If $\deg P > \deg Q$, the limit is infinity (positive or negative, depending on the sign).

**示例 / Example:**  
$\lim_{x \to \infty} \frac{3x^2 + 2x + 1}{5x^2 - x + 4} = \frac{3}{5}$
