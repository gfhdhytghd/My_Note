# 期望值（EV）/ Expected Value (EV)

## 定义 / Definition
- 期望值是一次赌注在大量重复下的平均收益。The expected value of a gamble is the average payoff over many repetitions.
- 计算方式为各结果的“概率 × 该结果的取值”之和。Compute as the sum of each outcome’s probability times its value.

## 公式 / Formula
- $EV=\sum_i P_i V_i$。

## 例子 / Example
- 假设抛一枚公平硬币：正面赢 $\$2$；反面输 $\$1$。Suppose a fair coin: heads wins $\$2$, tails loses $\$1$.
- 期望值：$EV=0.5\times 2+0.5\times(-1)=1-0.5=\mathbf{0.5}$（即 $\$0.50$）。Expected value is $\$0.50$.

## 启示 / Takeaway
- EV 用于在不确定条件下比较方案的平均回报；注意它不刻画风险厌恶或方差，仅刻画平均水平。EV compares alternatives by average payoff under uncertainty; it does not capture risk attitudes or variance, only the mean.
