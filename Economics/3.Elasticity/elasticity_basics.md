# 弹性基础 / Elasticity Basics

## 1. 弹性核心概念 / Core Elasticity Concept

### 1.1 定义 / Definition

**弹性**衡量一个变量对另一个变量百分比变化的响应程度。  
**Elasticity** measures the percentage response of one variable to a percentage change in another variable.

$$E_{Y,X} = \frac{\%\Delta Y}{\%\Delta X}$$

### 1.2 计算方法 / Calculation Methods

#### 点弹性 / Point Elasticity
$$\displaystyle E = \frac{dQ}{dP} \cdot \frac{P}{Q}$$

#### 弧弹性（中点法）/ Arc Elasticity (Midpoint Method)
$$\begin{align}
\%\Delta Q &= \frac{Q_2 - Q_1}{(Q_1 + Q_2)/2} \\
\%\Delta P &= \frac{P_2 - P_1}{(P_1 + P_2)/2} \\
E &= \frac{\%\Delta Q}{\%\Delta P}
\end{align}$$

**中点法**使用平均值避免起点偏差。  
**Midpoint method** uses averages to avoid start-point bias.

---

## 2. 主要弹性类型 / Main Elasticity Types

### 2.1 需求价格弹性 / Price Elasticity of Demand
$$E_d = \frac{\%\Delta Q_d}{\%\Delta P}$$

- 通常为负值 / Usually negative
- 解读时使用绝对值 / Interpret using absolute value

### 2.2 供给价格弹性 / Price Elasticity of Supply
$$E_s = \frac{\%\Delta Q_s}{\%\Delta P}$$

- 通常≥0 / Usually ≥0

### 2.3 收入弹性 / Income Elasticity
$$E_y = \frac{\%\Delta Q}{\%\Delta \text{Income}}$$

- $E_y > 0$：正常品 / Normal goods
- $E_y < 0$：低档品 / Inferior goods  
- $E_y > 1$：奢侈品 / Luxury goods

### 2.4 交叉价格弹性 / Cross-Price Elasticity
$$E_{x,y} = \frac{\%\Delta Q_x}{\%\Delta P_y}$$

- $E_{x,y} > 0$：替代品 / Substitutes
- $E_{x,y} < 0$：互补品 / Complements

---

## 3. 需求弹性分类 / Demand Elasticity Classification

- $|E_d| > 1$：**富有弹性** / **Elastic**
- $|E_d| = 1$：**单位弹性** / **Unit elastic**  
- $|E_d| < 1$：**缺乏弹性** / **Inelastic**

**线性需求曲线特征**：上段更有弹性，中点单位弹性，下段较无弹性。  
**Linear demand curve**: top elastic → midpoint unit → bottom inelastic.

---

## 4. 弹性决定因素 / Elasticity Determinants

### 4.1 需求弹性决定因素 / Demand Elasticity Determinants
- 替代品数量：替代品越多 → 弹性越大 / More substitutes → more elastic
- 预算占比：占比越高 → 更有弹性 / Bigger budget share → more elastic
- 商品性质：奢侈品 > 必需品 / Luxuries > necessities
- 时间跨度：时间越长 → 更有弹性 / Longer horizon → more elastic
- 市场范围：定义越窄 → 更有弹性 / Narrower market → more elastic

### 4.2 供给弹性特征 / Supply Elasticity Characteristics
供给弹性通常**长期 > 短期**。  
Supply is typically **more elastic in the long run**.

---

## 5. 总收益关系 / Total Revenue Relationship

$$TR = P \times Q$$

**价格上调时** / When price increases:
- $|E_d| > 1$ → **总收益下降** / **TR falls**
- $|E_d| < 1$ → **总收益上升** / **TR rises**  
- $|E_d| = 1$ → **总收益不变** / **TR unchanged**

---

## 6. 特殊情况 / Special Cases

- **完全无弹性**：$|E_d| = 0$（垂直线）/ **Perfectly inelastic** (vertical line)
- **完全有弹性**：$|E_d| = \infty$（水平线）/ **Perfectly elastic** (horizontal line)
