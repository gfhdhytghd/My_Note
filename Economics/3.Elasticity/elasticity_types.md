# 弹性类型分类 / Elasticity Types Classification

## 1. 需求弹性分类标准 / Demand Elasticity Classification Standards

根据需求价格弹性系数的大小，可将需求分为五种类型。  
Based on the price elasticity of demand coefficient, demand can be classified into five types.

---

## 2. 五种弹性类型 / Five Elasticity Types

### 2.1 绝对不弹性 / Perfectly Inelastic
$$|E_d| = 0$$

**特征 / Characteristics:**
- 价格变化时需求量完全不变 / Quantity demanded remains constant regardless of price changes
- 需求曲线为垂直线 / Demand curve is vertical
- 总收益与价格成正比 / Total revenue is proportional to price

**实例 / Examples:**
- 急救药物（如胰岛素）/ Emergency medications (e.g., insulin)
- 某些必需品的短期需求 / Short-term demand for certain necessities

### 2.2 相对不弹性 / Relatively Inelastic  
$$0 < |E_d| < 1$$

**特征 / Characteristics:**
- 需求量变化幅度小于价格变化幅度 / Quantity change is smaller than price change
- 价格上升时总收益增加 / Total revenue increases when price rises
- 需求曲线相对陡峭 / Relatively steep demand curve

**实例 / Examples:**
- 汽油 / Gasoline
- 食盐 / Salt
- 基本食品 / Basic food items

### 2.3 单位弹性 / Unit Elastic
$$|E_d| = 1$$

**特征 / Characteristics:**
- 需求量变化幅度等于价格变化幅度 / Quantity change equals price change
- 价格变化时总收益保持不变 / Total revenue remains constant when price changes
- 需求曲线呈双曲线形状 / Demand curve is hyperbolic

**数学表达 / Mathematical Expression:**
$$P \times Q = \text{constant}$$

### 2.4 相对弹性 / Relatively Elastic
$$1 < |E_d| < \infty$$

**特征 / Characteristics:**
- 需求量变化幅度大于价格变化幅度 / Quantity change is larger than price change  
- 价格上升时总收益减少 / Total revenue decreases when price rises
- 需求曲线相对平缓 / Relatively flat demand curve

**实例 / Examples:**
- 奢侈品 / Luxury goods
- 非必需品 / Non-essential goods
- 有较多替代品的商品 / Goods with many substitutes

### 2.5 绝对弹性 / Perfectly Elastic
$$|E_d| = \infty$$

**特征 / Characteristics:**
- 价格的微小变化导致需求量无限变化 / Tiny price changes cause infinite quantity changes
- 需求曲线为水平线 / Demand curve is horizontal
- 消费者对价格极其敏感 / Consumers are extremely price-sensitive

**实例 / Examples:**
- 完全竞争市场的产品 / Products in perfectly competitive markets
- 同质化商品的个别厂商面临的需求 / Individual firm demand in homogeneous goods markets

## 4. 线性需求曲线的弹性特征 / Elasticity Along Linear Demand Curve

**重要特征**：线性需求曲线上不同点的弹性不同。  
**Important feature**: Elasticity varies along a linear demand curve.

- **上段**：$|E_d| > 1$（富有弹性）/ **Upper portion**: elastic
- **中点**：$|E_d| = 1$（单位弹性）/ **Midpoint**: unit elastic  
- **下段**：$|E_d| < 1$（缺乏弹性）/ **Lower portion**: inelastic

---

## 5. 总收益与弹性关系 / Total Revenue and Elasticity Relationship

$$TR = P \times Q$$

**价格上调时的收益变化 / Revenue changes when price increases:**

- **富有弹性区间**（$|E_d| > 1$）：总收益下降 / **Elastic range**: TR falls
- **单位弹性点**（$|E_d| = 1$）：总收益最大化 / **Unit elastic point**: TR maximized
- **缺乏弹性区间**（$|E_d| < 1$）：总收益上升 / **Inelastic range**: TR rises
