# 弹性决定因素 / Elasticity Determinants

## 1. 需求价格弹性决定因素 / Price Elasticity of Demand Determinants

### 1.1 替代品的可获得性 / Availability of Substitutes

**核心原理**：替代品越多，需求越有弹性。  
**Core principle**: More substitutes → more elastic demand.

**具体表现 / Specific manifestations:**
- **替代品丰富**：消费者容易转向其他商品 / **Many substitutes**: consumers easily switch
- **替代品稀少**：消费者选择有限，需求较无弹性 / **Few substitutes**: limited choices, inelastic demand
- **完美替代品**：需求极其有弹性 / **Perfect substitutes**: highly elastic demand

**实例 / Examples:**
- 可口可乐x c（替代品多）vs 胰岛素（替代品少）/ Coca-Cola (many substitutes) vs insulin (few substitutes)

### 1.2 预算中的重要性 / Importance in Budget

**核心原理**：商品支出占预算比例越高，需求越有弹性。  
**Core principle**: Higher budget share → more elastic demand.

**逻辑解释 / Logic explanation:**
- **高预算占比**：价格变化显著影响消费者福利 / **High budget share**: price changes significantly affect consumer welfare
- **低预算占比**：价格变化影响相对较小 / **Low budget share**: price changes have relatively small impact

**实例 / Examples:**
- 住房（高预算占比，有弹性）/ Housing (high budget share, elastic)
- 口香糖（低预算占比，无弹性）/ Chewing gum (low budget share, inelastic)

### 1.3 商品性质 / Nature of Goods

**分类比较 / Classification comparison:**

| 商品类型 / Good Type | 弹性特征 / Elasticity | 原因 / Reason |
|---|---|---|
| 奢侈品 / Luxury goods | 高弹性 / High elasticity | 可推迟购买 / Can postpone purchase |
| 必需品 / Necessity goods | 低弹性 / Low elasticity | 生活必需 / Essential for living |
| 正常品 / Normal goods | 中等弹性 / Moderate elasticity | 介于两者之间 / Between luxury and necessity |

### 1.4 时间跨度 / Time Horizon

**时间效应**：时间越长，需求越有弹性。  
**Time effect**: Longer time period → more elastic demand.

**短期 vs 长期 / Short-run vs Long-run:**
- **短期**：消费习惯固化，调整困难 / **Short-run**: habits fixed, difficult to adjust
- **长期**：有时间寻找替代品和调整消费模式 / **Long-run**: time to find substitutes and adjust consumption patterns

**实例 / Example:**
汽油需求：短期相对无弹性，长期相对有弹性  
Gasoline demand: relatively inelastic in short-run, relatively elastic in long-run

### 1.5 市场定义的范围 / Scope of Market Definition

**定义效应**：市场定义越窄，需求越有弹性。  
**Definition effect**: Narrower market definition → more elastic demand.

**层级比较 / Hierarchical comparison:**
- **具体品牌**：高弹性（如"雀巢咖啡"）/ **Specific brand**: high elasticity (e.g., "Nescafé")
- **商品类别**：中等弹性（如"咖啡"）/ **Product category**: moderate elasticity (e.g., "coffee")  
- **大类商品**：低弹性（如"饮料"）/ **Broad category**: low elasticity (e.g., "beverages")

## 2. 供给价格弹性决定因素 / Price Elasticity of Supply Determinants

### 2.1 生产调整的难易程度 / Ease of Production Adjustment

**调整能力**：生产越容易调整，供给越有弹性。  
**Adjustment capability**: Easier production adjustment → more elastic supply.

**影响因素 / Influencing factors:**
- 生产技术复杂程度 / Production technology complexity
- 生产设备专用性 / Specificity of production equipment
- 劳动力技能要求 / Labor skill requirements

### 2.2 时间跨度 / Time Period

**供给弹性时间特征**：长期 > 短期  
**Supply elasticity time characteristic**: Long-run > Short-run

**三个时间段 / Three time periods:**
1. **瞬时期**：供给完全无弹性 / **Market period**: perfectly inelastic supply
2. **短期**：部分要素可调整 / **Short-run**: some factors adjustable  
3. **长期**：所有要素可调整 / **Long-run**: all factors adjustable

### 2.3 生产要素的可获得性 / Availability of Production Factors

**要素约束**：生产要素越稀缺，供给越无弹性。  
**Factor constraints**: Scarcer production factors → less elastic supply.

**考虑因素 / Considerations:**
- 原材料供应 / Raw material supply
- 熟练劳动力 / Skilled labor
- 资本设备 / Capital equipment

### 2.4 库存水平 / Inventory Levels

**库存效应**：库存越充足，短期供给越有弹性。  
**Inventory effect**: More inventory → more elastic short-run supply.

## 3. 收入弹性决定因素 / Income Elasticity Determinants

### 3.1 商品类型分类 / Good Type Classification

**按收入弹性分类 / Classification by income elasticity:**
- $E_y > 1$：奢侈品 / Luxury goods  
- $0 < E_y < 1$：必需品 / Necessity goods
- $E_y < 0$：低档品 / Inferior goods

### 3.2 消费者收入水平 / Consumer Income Level

**收入效应**：同一商品在不同收入水平下弹性不同。  
**Income effect**: Same good has different elasticity at different income levels.

**实例 / Example:**
- 对低收入者：肉类可能是奢侈品 / For low-income: meat might be luxury
- 对高收入者：肉类可能是必需品 / For high-income: meat might be necessity

## 4. 交叉价格弹性决定因素 / Cross-Price Elasticity Determinants

### 4.1 商品关系类型 / Type of Good Relationship

**关系强度**：商品关系越密切，交叉弹性绝对值越大。  
**Relationship strength**: Closer relationship → higher absolute cross-elasticity.

**关系类型 / Relationship types:**
- **强替代品**：高正交叉弹性 / **Close substitutes**: high positive cross-elasticity
- **强互补品**：高负交叉弹性 / **Close complements**: high negative cross-elasticity
- **独立商品**：接近零交叉弹性 / **Independent goods**: near-zero cross-elasticity

### 4.2 消费习惯和偏好 / Consumption Habits and Preferences

**偏好影响**：消费者偏好影响商品间的替代程度。  
**Preference impact**: Consumer preferences affect degree of substitution between goods.
