# 长期成本 / Long-Run Costs

- 定义 / Definition：长期是指固定要素（如厂房、机器）可调整的时间跨度；所有成本均可变。/ Long run is a horizon where fixed inputs (e.g., plant, machinery) are adjustable; all costs are variable.
- 长期平均总成本 / Long-Run ATC (LRATC)：不同厂房规模的短期平均总成本曲线（SRATC）的“下包络”，给出各产量下的最低单位成本。/ LRATC is the lower envelope of SRATC curves across plant sizes, showing the minimum unit cost for each output.
- 规模经济 / Economies of Scale：等比例扩大所有投入使 $LRATC$ 下降（增加规模报酬）。/ Proportional scaling of all inputs lowers $LRATC$ (increasing returns to scale).
- 规模不经济 / Diseconomies of Scale：等比例扩大所有投入使 $LRATC$ 上升（递减规模报酬）。/ Proportional scaling of all inputs raises $LRATC$ (decreasing returns to scale).
- 短期约束 / Short-Run Constraint：短期内固定成本既定，企业只能在一条既定的 $SRATC$ 上调整产量。/ In the short run, fixed costs are committed, so the firm moves along a single chosen $SRATC$.
- 长期选择 / Long-Run Choice：长期可在不同厂房规模间切换，对每个 $Q$ 选择成本最低的 $SRATC$，从而描绘出 $LRATC$。/ In the long run, the firm chooses among plant sizes, picking the lowest cost at each $Q$, which traces out $LRATC$.
