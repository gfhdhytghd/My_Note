# 生产函数 / Production Function

## 基本概念 / Basic Concepts

### 生产函数定义 / Production Function Definition

**定义 / Definition：** 描述投入要素与产出之间技术关系的函数 / A function that describes the technical relationship between input factors and output

**一般形式 / General Form：**
$$Q = f(L, K)$$

其中 / Where：
- $Q$ = 产出 / Output
- $L$ = 劳动投入 / Labor input
- $K$ = 资本投入 / Capital input

## 短期生产函数 / Short-Run Production Function

### 特点 / Characteristics

- 至少有一种生产要素固定 / At least one factor of production is fixed
- 通常资本固定，劳动可变 / Usually capital is fixed, labor is variable
- 生产函数简化为：$Q = f(L)$ / Simplified to: $Q = f(L)$

### 边际产量 / Marginal Product (MP)

**定义 / Definition：** 增加一单位可变投入所增加的产出 / The additional output from adding one more unit of variable input

**公式 / Formula：**
$$MP_L = \frac{\Delta Q}{\Delta L}$$

### 边际产量递减规律 / Law of Diminishing Marginal Product

**内容 / Content：** 在固定投入不变的情况下，随着可变投入增加，边际产量最终会递减 / With fixed inputs constant, as variable inputs increase, marginal product will eventually decrease

**原因 / Reasons：**
- 固定投入的限制 / Limitations of fixed inputs
- 拥挤效应 / Crowding effect
- 管理效率下降 / Declining management efficiency

## 成本概念 / Cost Concepts

### 总成本 / Total Cost (TC)

**公式 / Formula：**
$$TC = FC + VC$$

其中 / Where：
- $FC$ = 固定成本 / Fixed Cost
- $VC$ = 可变成本 / Variable Cost

### 平均成本 / Average Costs

#### 平均固定成本 / Average Fixed Cost (AFC)
$$AFC = \frac{FC}{Q}$$

#### 平均可变成本 / Average Variable Cost (AVC)
$$AVC = \frac{VC}{Q}$$

#### 平均总成本 / Average Total Cost (ATC)
$$ATC = \frac{TC}{Q} = AFC + AVC$$

### 边际成本 / Marginal Cost (MC)

**定义 / Definition：** 增加一单位产出所增加的总成本 / The additional total cost from producing one more unit of output

**公式 / Formula：**
$$MC = \frac{\Delta TC}{\Delta Q}$$

**重要关系 / Important Relationship：**
$$MC = \frac{\Delta VC}{\Delta Q}$$

## 成本曲线特征 / Cost Curve Characteristics

### 短期成本曲线 / Short-Run Cost Curves

1. **AFC曲线 / AFC Curve**
   - 向右下方倾斜 / Downward sloping
   - 随着产量增加而递减 / Decreases as output increases

2. **AVC曲线 / AVC Curve**
   - 先下降后上升 / First decreases then increases
   - U形曲线 / U-shaped curve

3. **ATC曲线 / ATC Curve**
   - U形曲线 / U-shaped curve
   - 在AVC曲线之上 / Above the AVC curve

4. **MC曲线 / MC Curve**
   - 先下降后上升 / First decreases then increases
   - 通过AVC和ATC的最低点 / Passes through the minimum points of AVC and ATC

### 成本曲线关系 / Cost Curve Relationships

- $MC < AVC$ 时，AVC下降 / When $MC < AVC$, AVC decreases
- $MC > AVC$ 时，AVC上升 / When $MC > AVC$, AVC increases
- $MC = AVC$ 时，AVC达到最小值 / When $MC = AVC$, AVC reaches minimum

## 长期成本 / Long-Run Costs

### 长期平均总成本 / Long-Run Average Total Cost (LRATC)

**特点 / Characteristics：**
- 所有生产要素都可变 / All factors of production are variable
- 反映规模经济效应 / Reflects economies of scale

### 规模经济 / Economies of Scale

#### 规模报酬递增 / Increasing Returns to Scale
- $LRATC$ 下降 / $LRATC$ decreases
- 平均成本随产量增加而下降 / Average cost decreases as output increases

#### 规模报酬不变 / Constant Returns to Scale
- $LRATC$ 不变 / $LRATC$ remains constant
- 平均成本不随产量变化 / Average cost doesn't change with output

#### 规模报酬递减 / Decreasing Returns to Scale
- $LRATC$ 上升 / $LRATC$ increases
- 平均成本随产量增加而上升 / Average cost increases as output increases
