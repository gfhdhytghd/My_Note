# 指数与对数函数 / Exponential and Logarithmic Functions

## 指数函数 / Exponential Function

**定义 / Definition：**  
指数函数的标准形式为 $f(x) = a^x$，其中 $a>0$ 且 $a \neq 1$。  
The standard form of the exponential function is $f(x) = a^x$, where $a>0$ and $a \neq 1$.

**性质 / Properties：**
- 定义域 / Domain：$\mathbb{R}$
- 值域 / Range：$(0, +\infty)$
- 单调性 / Monotonicity：$a>1$ 时递增，$0<a<1$ 时递减  
  Increasing if $a>1$, decreasing if $0<a<1$

---

## 对数函数 / Logarithmic Function

**定义 / Definition：**  
对数函数是指数函数的反函数，形式为 $f(x) = \log_a x$，其中 $a>0$ 且 $a \neq 1$。  
The logarithmic function is the inverse of the exponential function, in the form $f(x) = \log_a x$, where $a>0$ and $a \neq 1$.

**性质 / Properties：**
- 定义域 / Domain：$(0, +\infty)$
- 值域 / Range：$\mathbb{R}$
- 单调性 / Monotonicity：$a>1$ 时递增，$0<a<1$ 时递减  
  Increasing if $a>1$, decreasing if $0<a<1$

---

## 基本性质 / Basic Properties

- $a^{\log_a x} = x$，$x>0$  
  $a^{\log_a x} = x$, $x>0$
- $\log_a(a^x) = x$，$x \in \mathbb{R}$  
  $\log_a(a^x) = x$, $x \in \mathbb{R}$
- $\log_a 1 = 0$，$\log_a a = 1$  
  $\log_a 1 = 0$, $\log_a a = 1$

---

## 常用底数 / Common Bases

- $e$：自然对数 $\ln x = \log_e x$  
  Natural logarithm: $\ln x = \log_e x$
- $10$：常用对数 $\log x = \log_{10} x$  
  Common logarithm: $\log x = \log_{10} x$

---

## 对数运算法则 / Logarithm Properties

设 $a > 0$, $a \neq 1$, $M > 0$, $N > 0$：

1. $\log_a(MN) = \log_a M + \log_a N$
2. $\log_a\left(\frac{M}{N}\right) = \log_a M - \log_a N$
3. $\log_a(M^p) = p\log_a M$
4. $\log_a M = \frac{\log_b M}{\log_b a}$ (换底公式 / Change of base formula)

---

## 例子 / Examples

**指数函数例子 / Exponential Function Examples：**
- $f(x) = 2^x$：定义域 $\mathbb{R}$，值域 $(0, +\infty)$，递增
- $f(x) = \left(\frac{1}{2}\right)^x$：定义域 $\mathbb{R}$，值域 $(0, +\infty)$，递减

**对数函数例子 / Logarithmic Function Examples：**
- $f(x) = \log_2 x$：定义域 $(0, +\infty)$，值域 $\mathbb{R}$，递增
- $f(x) = \ln x$：自然对数函数，定义域 $(0, +\infty)$，值域 $\mathbb{R}$
