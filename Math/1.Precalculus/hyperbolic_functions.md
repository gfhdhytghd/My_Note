# 双曲函数 / Hyperbolic Functions

## 基本定义 / Basic Definition

**双曲正弦函数 / Hyperbolic Sine Function：**  
$\sinh x = \dfrac{e^x - e^{-x}}{2}$

**双曲余弦函数 / Hyperbolic Cosine Function：**  
$\cosh x = \dfrac{e^x + e^{-x}}{2}$

**双曲正切函数 / Hyperbolic Tangent Function：**  
$\tanh x = \dfrac{\sinh x}{\cosh x} = \dfrac{e^x - e^{-x}}{e^x + e^{-x}}$

---

## 基本性质 / Basic Properties

**基本恒等式 / Basic Identities：**
- $\cosh^2 x - \sinh^2 x = 1$
- $1 - \tanh^2 x = \text{sech}^2 x$
- $\coth^2 x - 1 = \text{csch}^2 x$

**奇偶性 / Parity：**
- $\sinh(-x) = -\sinh x$，$\sinh x$ 是奇函数  
  $\sinh(-x) = -\sinh x$, $\sinh x$ is odd
- $\cosh(-x) = \cosh x$，$\cosh x$ 是偶函数  
  $\cosh(-x) = \cosh x$, $\cosh x$ is even

**导数 / Derivatives：**
- $\frac{d}{dx}\sinh x = \cosh x$
- $\frac{d}{dx}\cosh x = \sinh x$
- $\frac{d}{dx}\tanh x = \text{sech}^2 x$

---

## 图像特征 / Graph Characteristics

**$\sinh x$ 的图像 / Graph of $\sinh x$：**
- 类似于立方函数，通过原点 $(0,0)$
- 在 $x=0$ 处斜率为 $1$
- 严格递增函数

**$\cosh x$ 的图像 / Graph of $\cosh x$：**
- 类似于抛物线，但最低点为 $y=1$
- 在 $x=0$ 处达到最小值 $1$
- 关于 $y$ 轴对称

**$\tanh x$ 的图像 / Graph of $\tanh x$：**
- 类似于反正切函数，有水平渐近线 $y=\pm1$
- 通过原点 $(0,0)$
- 严格递增函数
