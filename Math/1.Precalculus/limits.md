# 极限 / Limits

## 1. 基本概念 / Basic Concepts

**定义 / Definition：**  
极限描述了当变量趋近某一特定值时，函数值的行为。  
Limit describes the behavior of a function as the variable approaches a specific value.

**数学记号 / Mathematical Notation：**  
$\lim_{x \to a} f(x) = L$  
表示当 $x$ 趋近于 $a$ 时，$f(x)$ 的极限为 $L$。  
Means as $x$ approaches $a$, the limit of $f(x)$ is $L$.

**常见极限性质 / Common Properties：**  
- 唯一性 / Uniqueness  
  极限值唯一。  
  The limit is unique.
- 四则运算 / Arithmetic  
  极限可进行加减乘除。  
  Limits can be added, subtracted, multiplied, and divided.

**例子 / Example：**  
$\lim_{x \to 0} \frac{\sin x}{x} = 1$  
当 $x$ 趋近于 $0$ 时，$\frac{\sin x}{x}$ 的极限为 $1$。  
As $x$ approaches $0$, the limit of $\frac{\sin x}{x}$ is $1$.

## 2. 直接代入不可用时的极限计算方法 / Methods for Limits When Direct Substitution Fails

**常见情形 / Common Situations：**  
有些极限在直接代入时会出现未定式（如 $0/0$、$\infty/\infty$），此时需用其他方法计算。  
Some limits result in indeterminate forms (such as $0/0$, $\infty/\infty$) when directly substituted, requiring other methods.

### 2.1 因式分解法 / Factorization

- 通过分解分子分母，约去相同因子后再代入。  
  Factor numerator and denominator, cancel common factors, then substitute.

**例 / Example：**  
$\lim_{x \to 1} \frac{x^2-1}{x-1} = \lim_{x \to 1} \frac{(x-1)(x+1)}{x-1} = \lim_{x \to 1} (x+1) = 2$

### 2.2 有理化 / Rationalization

- 对含有根号的表达式，乘以共轭式消去根号。  
  For expressions with radicals, multiply by the conjugate to eliminate the radical.

**例 / Example：**  
$\lim_{x \to 0} \frac{\sqrt{x+1}-1}{x} = \lim_{x \to 0} \frac{(\sqrt{x+1}-1)(\sqrt{x+1}+1)}{x(\sqrt{x+1}+1)} = \lim_{x \to 0} \frac{x}{x(\sqrt{x+1}+1)} = \lim_{x \to 0} \frac{1}{\sqrt{x+1}+1} = \frac{1}{2}$

### 2.3 洛必达法则 / L'Hôpital's Rule

- 对于 $0/0$ 或 $\infty/\infty$ 型，分别对分子分母求导再取极限。  
  For $0/0$ or $\infty/\infty$ forms, differentiate numerator and denominator, then take the limit.

**例 / Example：**  
$\lim_{x \to 0} \frac{\sin x}{x} = \lim_{x \to 0} \frac{\cos x}{1} = 1$

### 2.4 泰勒展开 / Taylor Expansion

- 用泰勒级数展开函数，取主要项计算极限。  
  Expand the function using Taylor series and use the leading terms to compute the limit.

**例 / Example：**  
$\lim_{x \to 0} \frac{1-\cos x}{x^2} = \lim_{x \to 0} \frac{\frac{1}{2}x^2}{x^2} = \frac{1}{2}$

## 3. 极限不可计算的几种情况 / Cases Where Limits Do Not Exist

- 左右极限不相等 / Left and Right Limits Are Not Equal  
  若 $\lim_{x \to a^-} f(x) \neq \lim_{x \to a^+} f(x)$，则极限不存在。  
  If $\lim_{x \to a^-} f(x) \neq \lim_{x \to a^+} f(x)$, the limit does not exist.

- 无界发散 / Unbounded Divergence  
  若函数趋于无穷大或无穷小，极限不存在。  
  If the function approaches infinity or negative infinity, the limit does not exist.

- 振荡 / Oscillation  
  若函数在趋近某点时不断振荡且无确定值，极限不存在。  
  If the function oscillates without approaching a fixed value, the limit does not exist.

**例子 / Examples：**  
- $\lim_{x \to 0} \frac{1}{x}$ 无界发散 / Unbounded divergence  
- $\lim_{x \to 0} \sin \frac{1}{x}$ 振荡 / Oscillation  
- $\lim_{x \to 0^-} \frac{1}{x} = -\infty,\ \lim_{x \to 0^+} \frac{1}{x} = +\infty$，左右极限不等 / Left and right limits are not equal

## 4. 相关概念 / Related Concepts

**连续性与极限 / Continuity and Limits：**  
函数在某点连续，当且仅当该点的极限值等于函数值。  
A function is continuous at a point if and only if the limit at that point equals the function value.

**单侧极限 / One-Sided Limits：**  
- 左极限 / Left Limit：$\lim_{x \to a^-} f(x)$
- 右极限 / Right Limit：$\lim_{x \to a^+} f(x)$

**无穷极限 / Infinite Limits：**  
当函数值无限增大或减小时，极限为无穷大或负无穷大。  
When function values increase or decrease without bound, the limit is infinity or negative infinity.
