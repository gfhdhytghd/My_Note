# 1. 实数 / Real Numbers

## 定义 / Definition

**Definition / 定义：**
Real numbers are a fundamental concept in mathematics that include all rational and irrational numbers.
实数是数学中的一个基本概念，包含所有有理数和无理数。

**Key Characteristics / 主要特征：**
- All numbers that can be represented on a number line
  可以在数轴上表示的所有数
- Include positive numbers, negative numbers, and zero
  包括正数、负数和零
- Include integers, fractions, decimals, and irrational numbers (such as √2, π)
  包括整数、分数、小数和无理数（如√2, π）

## 分类 / Classification

**Rational Numbers** ($\mathbb{Q}$): Numbers that can be expressed as a ratio of two integers (e.g., 1/2, 3, -5)
**有理数**（$\mathbb{Q}$）：可以表示为两个整数比值的数（如 1/2, 3, -5）

**Irrational Numbers** ($\mathbb{I}$ or $\mathbb{R} \setminus \mathbb{Q}$): Numbers that cannot be expressed as a ratio of two integers (e.g., √2, π, e)
**无理数**（$\mathbb{I}$ 或 $\mathbb{R} \setminus \mathbb{Q}$）：不能表示为两个整数比值的数（如 √2, π, e）

## 记号 / Notation

**Notation / 记号：** $\mathbb{R}$

The set of real numbers is continuous and complete, providing the foundation for calculus and advanced mathematics.
实数集合是连续且完备的，为微积分和高等数学提供了基础。

## 实数的性质 / Properties of Real Numbers

### 基本运算性质 / Basic Operations Properties

1. **加法交换律 / Commutative Property of Addition**
   $$a + b = b + a$$

2. **乘法交换律 / Commutative Property of Multiplication**
   $$a \times b = b \times a$$

3. **加法结合律 / Associative Property of Addition**
   $$(a + b) + c = a + (b + c)$$

4. **乘法结合律 / Associative Property of Multiplication**
   $$(a \times b) \times c = a \times (b \times c)$$

5. **分配律 / Distributive Property**
   $$a \times (b + c) = a \times b + a \times c$$

### 序的性质 / Order Properties

1. **三分性 / Trichotomy Property**
   对于任意两个实数 $a$ 和 $b$，必有且仅有以下三种情况之一成立：
   For any two real numbers $a$ and $b$, exactly one of the following is true:
   - $a < b$
   - $a = b$  
   - $a > b$

2. **传递性 / Transitivity**
   如果 $a < b$ 且 $b < c$，则 $a < c$
   If $a < b$ and $b < c$, then $a < c$
