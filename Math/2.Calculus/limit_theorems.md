# 极限定理 / Limit Theorems

## 1. 多项式分式极限最高次项法则 / Leading Term Rule for Rational Function Limits

**定理（中文）：**  
当 $x \to \infty$ 或 $x \to -\infty$ 时，多项式分式 $\frac{P(x)}{Q(x)}$ 的极限，只需比较分子分母的最高次项。  
- 若 $\deg P < \deg Q$，极限为 $0$。  
- 若 $\deg P = \deg Q$，极限为最高次项系数之比。  
- 若 $\deg P > \deg Q$，极限为无穷大（正或负，视系数符号而定）。

**Theorem (English):**  
As $x \to \infty$ or $x \to -\infty$, for a rational function $\frac{P(x)}{Q(x)}$, only the leading terms matter:  
- If $\deg P < \deg Q$, the limit is $0$.  
- If $\deg P = \deg Q$, the limit is the ratio of leading coefficients.  
- If $\deg P > \deg Q$, the limit is infinity (positive or negative, depending on the sign).

**示例 / Example:**  
$\lim_{x \to \infty} \frac{3x^2 + 2x + 1}{5x^2 - x + 4} = \frac{3}{5}$

## 2. 夹逼定理 / Squeeze Theorem

### 2.1 定义 / Definition

夹逼定理（也称为三明治定理）是微积分中的一个重要定理，用于计算极限。  
The Squeeze Theorem (also called the Sandwich Theorem) is an important theorem in calculus for evaluating limits.

**定理表述 / Theorem Statement：**

如果对于所有 $x$ 在某个区间内（除了可能 $x = a$），有：
If for all $x$ in some interval (except possibly $x = a$), we have:

$$g(x) \leq f(x) \leq h(x)$$

并且：
and:

$$\lim_{x \to a} g(x) = \lim_{x \to a} h(x) = L$$

那么：
then:

$$\lim_{x \to a} f(x) = L$$

### 2.2 几何直观 / Geometric Intuition

当两个函数 $g(x)$ 和 $h(x)$ 在 $x \to a$ 时都趋向于同一个极限 $L$，而函数 $f(x)$ 被"夹"在它们之间时，$f(x)$ 也必然趋向于 $L$。  
When two functions $g(x)$ and $h(x)$ both approach the same limit $L$ as $x \to a$, and function $f(x)$ is "squeezed" between them, then $f(x)$ must also approach $L$.

### 2.3 经典例子 / Classic Example

**例子1：** 计算 $\lim_{x \to 0} x^2 \sin\left(\frac{1}{x}\right)$  
**Example 1:** Evaluate $\lim_{x \to 0} x^2 \sin\left(\frac{1}{x}\right)$

**解 / Solution：**

由于 $-1 \leq \sin\left(\frac{1}{x}\right) \leq 1$，我们有：
Since $-1 \leq \sin\left(\frac{1}{x}\right) \leq 1$, we have:

$$-x^2 \leq x^2 \sin\left(\frac{1}{x}\right) \leq x^2$$

当 $x \to 0$ 时：
As $x \to 0$:

$$\lim_{x \to 0} (-x^2) = 0 \quad \text{and} \quad \lim_{x \to 0} x^2 = 0$$

因此，由夹逼定理：
Therefore, by the Squeeze Theorem:

$$\lim_{x \to 0} x^2 \sin\left(\frac{1}{x}\right) = 0$$

### 2.4 应用条件 / Application Conditions

1. **不等式关系 / Inequality Relationship：** 必须能够建立 $g(x) \leq f(x) \leq h(x)$ 的不等式关系  
   Must be able to establish the inequality relationship $g(x) \leq f(x) \leq h(x)$

2. **边界函数极限 / Boundary Function Limits：** $g(x)$ 和 $h(x)$ 在目标点必须有相同的极限  
   $g(x)$ and $h(x)$ must have the same limit at the target point

3. **连续性 / Continuity：** 边界函数在目标点附近必须连续（除了目标点本身）  
   Boundary functions must be continuous near the target point (except at the target point itself)

## 3. 中间值定理 / Intermediate Value Theorem

**定理（中文）：**  
设函数 $f(x)$ 在区间 $[a, b]$ 上连续，且 $f(a) \neq f(b)$。则对于任意介于 $f(a)$ 与 $f(b)$ 之间的数 $L$，必存在 $c \in (a, b)$，使得 $f(c) = L$。

**Theorem (English):**  
Suppose $f(x)$ is continuous on $[a, b]$ and $f(a) \neq f(b)$. Then for any $L$ between $f(a)$ and $f(b)$, there exists $c \in (a, b)$ such that $f(c) = L$.

**示例 / Example:**  
若 $f(1) = -2, f(3) = 4$，则 $f(x)$ 在 $[1,3]$ 上必有一点 $c$ 使 $f(c) = 0$。
