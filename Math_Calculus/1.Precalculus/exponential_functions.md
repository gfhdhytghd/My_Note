# 指数函数 / Exponential Functions

## 基本定义 / Basic Definition

**标准形式 / Standard Form：**  
指数函数的标准形式为 $f(x) = a^x$，其中 $a>0$ 且 $a \neq 1$。  
The standard form of the exponential function is $f(x) = a^x$, where $a>0$ and $a \neq 1$.

**性质 / Properties：**
- 定义域 / Domain：$\mathbb{R}$
- 值域 / Range：$(0, +\infty)$
- 单调性 / Monotonicity：$a>1$ 时递增，$0<a<1$ 时递减  
  Increasing if $a>1$, decreasing if $0<a<1$

---

## 自然常数 $e$ / The Mathematical Constant $e$

**定义 / Definition：**  
自然常数 $e$ 是一个重要的无理数，约等于 $2.71828$，在数学中广泛应用，尤其是在指数、对数、微积分等领域。  
The mathematical constant $e$ is an important irrational number, approximately $2.71828$, widely used in mathematics, especially in exponentials, logarithms, and calculus.

**极限定义 / Limit Definition：**  
$$
e = \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n
$$

**级数定义 / Series Definition：**  
$$
e = \sum_{n=0}^{\infty} \frac{1}{n!} = 1 + \frac{1}{1} + \frac{1}{2!} + \frac{1}{3!} + \cdots
$$

**性质 / Properties：**  
- $e$ 是使得 $\frac{d}{dx}e^x = e^x$ 成立的唯一实数。  
  $e$ is the unique real number such that $\frac{d}{dx}e^x = e^x$.
- $e$ 是自然对数的底数，即 $\ln x = \log_e x$。  
  $e$ is the base of the natural logarithm, i.e., $\ln x = \log_e x$.

---

## 自然指数函数 / Natural Exponential Function

**定义 / Definition：**  
自然指数函数 $f(x) = e^x$ 是最重要的指数函数，在微积分中具有特殊地位。  
The natural exponential function $f(x) = e^x$ is the most important exponential function, with special significance in calculus.

**性质 / Properties：**
- 定义域 / Domain：$\mathbb{R}$
- 值域 / Range：$(0, +\infty)$
- 单调性 / Monotonicity：严格递增 / Strictly increasing
- 导数 / Derivative：$\frac{d}{dx}e^x = e^x$

---

## 例子 / Examples

**指数函数例子 / Exponential Function Examples：**
- $f(x) = 2^x$：定义域 $\mathbb{R}$，值域 $(0, +\infty)$，递增
- $f(x) = \left(\frac{1}{2}\right)^x$：定义域 $\mathbb{R}$，值域 $(0, +\infty)$，递减
- $f(x) = e^x$：自然指数函数，定义域 $\mathbb{R}$，值域 $(0, +\infty)$，严格递增
