# 2. 分数与小数的互相转换 / Conversion Between Fractions and Decimals

## 1. 分数转小数 / Converting Fractions to Decimals

Fractions (such as $\frac{a}{b}$) can be converted to decimals by dividing the numerator by the denominator. For example:
分数（如 $\frac{a}{b}$）可以通过分子除以分母得到对应的小数。例如：

### 基本例子 / Basic Examples

- $\frac{1}{2} = 0.5$
- $\frac{3}{4} = 0.75$
- $\frac{1}{3} = 0.333\ldots$ (repeating decimal, written as $0.\overline{3}$)
  $\frac{1}{3} = 0.333\ldots$（循环小数，记作 $0.\overline{3}$）

### 转换步骤 / Steps

1. Divide the numerator by the denominator.
   用分子除以分母。
2. If the division doesn't terminate, the result is either a terminating decimal or an infinite repeating decimal.
   若除不尽，则结果为有限小数或无限循环小数。

## 2. 小数转分数 / Converting Decimals to Fractions

### 有限小数 / Terminating Decimals

**Terminating decimals / 有限小数**: Write directly as a fraction with denominator 10, 100, 1000, etc., then simplify.
**有限小数**：直接写成分数，分母为 $10$、$100$、$1000$ 等，然后约分。

#### 例子 / Examples

- $0.25 = \frac{25}{100} = \frac{1}{4}$
- $0.6 = \frac{6}{10} = \frac{3}{5}$
- $0.125 = \frac{125}{1000} = \frac{1}{8}$

### 无限循环小数 / Infinite Repeating Decimals

**Infinite repeating decimals / 无限循环小数**: Set up a variable, use algebraic equations to eliminate the decimal part, and convert to a fraction.
**无限循环小数**：设未知数，利用等式消去小数部分，转化为分数。

#### 方法 / Method

设 $x = 0.\overline{d_1d_2...d_n}$（其中 $d_1d_2...d_n$ 为循环节）
Let $x = 0.\overline{d_1d_2...d_n}$ (where $d_1d_2...d_n$ is the repeating block)

则 $10^n \cdot x = d_1d_2...d_n.\overline{d_1d_2...d_n}$
Then $10^n \cdot x = d_1d_2...d_n.\overline{d_1d_2...d_n}$

相减得：$(10^n - 1) \cdot x = d_1d_2...d_n$
Subtracting: $(10^n - 1) \cdot x = d_1d_2...d_n$

所以：$x = \frac{d_1d_2...d_n}{10^n - 1}$
Therefore: $x = \frac{d_1d_2...d_n}{10^n - 1}$

#### 例子 / Examples

**例1 / Example 1:** $x = 0.\overline{3}$
$$
10x = 3.\overline{3} \\
10x - x = 3.\overline{3} - 0.\overline{3} \\
9x = 3 \implies x = \frac{1}{3}
$$

**例2 / Example 2:** $x = 0.\overline{142857}$
$$
10^6 x = 142857.\overline{142857} \\
10^6 x - x = 142857 \\
999999x = 142857 \\
x = \frac{142857}{999999} = \frac{1}{7}
$$

**例3 / Example 3:** $x = 0.1\overline{6}$
$$
x = 0.1666... \\
10x = 1.666... \\
100x = 16.666... \\
100x - 10x = 16.666... - 1.666... \\
90x = 15 \\
x = \frac{15}{90} = \frac{1}{6}
$$

## 判断小数类型 / Determining Decimal Types

### 有限小数的判别 / Identifying Terminating Decimals

一个最简分数 $\frac{a}{b}$ 能化为有限小数，当且仅当分母 $b$ 只含有质因数 2 和 5。
A fraction $\frac{a}{b}$ in lowest terms can be converted to a terminating decimal if and only if the denominator $b$ has only 2 and 5 as prime factors.

#### 例子 / Examples

- $\frac{1}{4} = \frac{1}{2^2}$ → 有限小数 / terminating decimal
- $\frac{3}{8} = \frac{3}{2^3}$ → 有限小数 / terminating decimal  
- $\frac{7}{20} = \frac{7}{2^2 \times 5}$ → 有限小数 / terminating decimal
- $\frac{1}{3}$ → 循环小数 / repeating decimal（分母含有质因数3）
- $\frac{2}{7}$ → 循环小数 / repeating decimal（分母含有质因数7）

## 总结 / Summary

- Fractions and decimals can be converted to each other; terminating decimals correspond to finite fractions, repeating decimals correspond to rational number fractions.
  分数和小数可以互相转换，有限小数对应有限分数，循环小数对应有理数分数。
- Irrational numbers (such as $\sqrt{2}$, $\pi$) cannot be written exactly as fractions or terminating/repeating decimals.
  无理数（如 $\sqrt{2}$、$\pi$）不能精确写成分数或有限/循环小数。
- 分母只含质因数2和5的最简分数对应有限小数，其他有理数对应循环小数。
  Reduced fractions with denominators containing only prime factors 2 and 5 correspond to terminating decimals; other rational numbers correspond to repeating decimals.
