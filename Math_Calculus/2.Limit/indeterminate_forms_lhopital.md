# 不定式与洛必达法则 / Indeterminate Forms and L'Hopital's Rule

## 常见不定式 / Common Indeterminate Forms
常见不定式包括$0/0,\ \infty/\infty,\ 0\cdot\infty,\ \infty-\infty,\ 0^0,\ 1^\infty,\ \infty^0$。  
Common indeterminate forms include $0/0,\ \infty/\infty,\ 0\cdot\infty,\ \infty-\infty,\ 0^0,\ 1^\infty,\ \infty^0$.

洛必达法则最直接适用于分式形式的$0/0$与$\infty/\infty$，所以很多题的第一步不是求导，而是先改写。  
L'Hopital's rule applies most directly to quotient forms of type $0/0$ and $\infty/\infty$, so the first step in many problems is not differentiation but rewriting.

## 如何改写成分式 / How to Rewrite into a Quotient
### $0\cdot\infty$
若$f(x)\to0$且$g(x)\to\infty$，则$f(x)g(x)$可改写为
If $f(x)\to0$ and $g(x)\to\infty$, then $f(x)g(x)$ can be rewritten as
$$
\frac{f(x)}{1/g(x)}
\quad\text{或}\quad
\frac{g(x)}{1/f(x)}.
$$
这样常能化成$0/0$或$\infty/\infty$。  
This often turns the expression into $0/0$ or $\infty/\infty$.

### $\infty-\infty$
遇到$\infty-\infty$时，通常先通分或有理化。  
For $\infty-\infty$, the usual move is to combine into one fraction or rationalize.

例如$\sqrt{u(x)}-\sqrt{v(x)}$可乘以共轭$\sqrt{u(x)}+\sqrt{v(x)}$。  
For example, $\sqrt{u(x)}-\sqrt{v(x)}$ can be multiplied by the conjugate $\sqrt{u(x)}+\sqrt{v(x)}$.

### 幂指型 $0^0,\ 1^\infty,\ \infty^0$
若$y=f(x)^{g(x)}$且$f(x)>0$，先取对数：
If $y=f(x)^{g(x)}$ with $f(x)>0$, first take logs:
$$
\ln y=g(x)\ln f(x).
$$
先求$L=\lim\ln y$，最后再回到
First compute $L=\lim\ln y$, then return to
$$
\lim y=e^L.
$$

## 速记例子 / Quick Examples
- $\lim_{x\to0^+}x\ln x$是$0\cdot(-\infty)$，可写成$\dfrac{\ln x}{1/x}$后再用洛必达。  
  $\lim_{x\to0^+}x\ln x$ is of type $0\cdot(-\infty)$, so rewrite it as $\dfrac{\ln x}{1/x}$ before using L'Hopital.
- $\lim_{x\to\infty}(\sqrt{x^2+x}-x)$是$\infty-\infty$，可先乘共轭化成分式。  
  $\lim_{x\to\infty}(\sqrt{x^2+x}-x)$ is of type $\infty-\infty$, so rationalize first.
- $\lim_{x\to0}(1+x)^{1/x}$是$1^\infty$，令$y=(1+x)^{1/x}$，则$\ln y=\dfrac{\ln(1+x)}{x}$为$0/0$。  
  $\lim_{x\to0}(1+x)^{1/x}$ is of type $1^\infty$; let $y=(1+x)^{1/x}$, then $\ln y=\dfrac{\ln(1+x)}{x}$ is $0/0$.

## 做题提醒 / Problem-Solving Reminders
1. 先辨认不定式类型，再决定是通分、有理化、倒数改写还是取对数。  
   Identify the indeterminate form first, then choose between combining fractions, rationalizing, reciprocal rewriting, or logarithms.
2. 不要把洛必达当成“见极限就求导”的默认动作。  
   Do not treat L'Hopital as the default move for every limit.
3. 每次使用洛必达后，要重新检查新极限是否仍是不定式。  
   After each application of L'Hopital, re-check whether the new limit is still indeterminate.
