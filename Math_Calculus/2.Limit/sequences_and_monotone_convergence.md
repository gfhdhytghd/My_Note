# 数列与单调收敛 / Sequences and Monotone Convergence

## 基本定义 / Basic Definition
数列可以看成定义在正整数上的函数，写作$a_1,a_2,a_3,\dots$。  
A sequence can be viewed as a function whose domain is the positive integers, written as $a_1,a_2,a_3,\dots$.

若存在实数$L$使得$n\to\infty$时$a_n\to L$，则称数列$\{a_n\}$收敛到$L$；若极限不存在、无界增长或持续振荡，则称其发散。  
If there exists a real number $L$ such that $a_n\to L$ as $n\to\infty$, then the sequence $\{a_n\}$ converges to $L$; if the limit does not exist, grows without bound, or keeps oscillating, then it diverges.

## 单调性与有界性 / Monotonicity and Boundedness
- 单调递增：对所有充分大的$n$，有$a_{n+1}\ge a_n$。  
  Monotonically increasing: for all sufficiently large $n$, we have $a_{n+1}\ge a_n$.
- 单调递减：对所有充分大的$n$，有$a_{n+1}\le a_n$。  
  Monotonically decreasing: for all sufficiently large $n$, we have $a_{n+1}\le a_n$.
- 有上界：存在常数$M$使$a_n\le M$。  
  Bounded above: there exists a constant $M$ such that $a_n\le M$.
- 有下界：存在常数$m$使$a_n\ge m$。  
  Bounded below: there exists a constant $m$ such that $a_n\ge m$.

单调性本身不保证收敛，但“单调 + 有界”经常足够。  
Monotonicity alone does not guarantee convergence, but “monotone + bounded” is often enough.

## 单调收敛定理 / Monotone Convergence Theorem
若数列单调递增且有上界，则它收敛；若数列单调递减且有下界，则它也收敛。  
If a sequence is monotonically increasing and bounded above, then it converges; if it is monotonically decreasing and bounded below, it also converges.

更精确地说，递增有上界的数列收敛到其上确界，递减有下界的数列收敛到其下确界。  
More precisely, an increasing sequence bounded above converges to its supremum, and a decreasing sequence bounded below converges to its infimum.

## 交错数列 / Alternating Sequences
交错数列通常指正负号交替出现，例如$a_n=(-1)^n$或$a_n=(-1)^{n+1}b_n$。  
An alternating sequence usually means the signs alternate, for example $a_n=(-1)^n$ or $a_n=(-1)^{n+1}b_n$.

$(-1)^n$本身不收敛，因为它在$1$和$-1$之间来回跳动。  
$(-1)^n$ itself does not converge because it keeps jumping between $1$ and $-1$.

若交错数列的振幅趋于$0$，则它常常收敛到$0$；典型例子是$\dfrac{(-1)^n}{n}\to0$。  
If the amplitude of an alternating sequence goes to $0$, then it often converges to $0$; a standard example is $\dfrac{(-1)^n}{n}\to0$.

## 数列版夹逼定理 / Squeeze Theorem for Sequences
若对所有充分大的$n$都有$u_n\le a_n\le v_n$，且
If for all sufficiently large $n$ we have $u_n\le a_n\le v_n$, and
$$
\lim_{n\to\infty}u_n=\lim_{n\to\infty}v_n=L,
$$
则
then
$$
\lim_{n\to\infty}a_n=L.
$$

例如
For example,
$$
-\frac{1}{n}\le\frac{(-1)^n}{n}\le\frac{1}{n},
$$
左右两边都趋于$0$，所以$\dfrac{(-1)^n}{n}\to0$。  
both outer sequences approach $0$, so $\dfrac{(-1)^n}{n}\to0$.

## 做题检查点 / Quick Checklist
1. 先看数列是否单调。  
   First check whether the sequence is monotone.
2. 再看它是否有上界或下界。  
   Then check whether it is bounded above or below.
3. 遇到交错项时，先看绝对值是否趋于$0$。  
   For alternating terms, first check whether the absolute value goes to $0$.
4. 遇到振荡但振幅缩小的表达式，优先考虑夹逼。  
   For oscillatory expressions with shrinking amplitude, consider the squeeze theorem first.
