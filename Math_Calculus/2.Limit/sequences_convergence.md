# 数列与收敛 / Sequences and Convergence

## 定义与基本判断 / Definitions and Basic Checks
数列（sequence）可以看成定义在正整数集上的函数，写作$\{a_n\}_{n=1}^\infty$。若存在实数$L$使得当$n\to\infty$时$a_n\to L$，则称数列收敛到$L$；否则称其发散。  
A sequence can be viewed as a function on the positive integers, written as $\{a_n\}_{n=1}^\infty$. If there exists a real number $L$ such that $a_n\to L$ as $n\to\infty$, then the sequence converges to $L$; otherwise it diverges.

单调性与有界性是最先检查的两个性质：单调递增指对充分大的$n$有$a_{n+1}\ge a_n$，单调递减指对充分大的$n$有$a_{n+1}\le a_n$；有上界表示存在$M$使得$a_n\le M$，有下界表示存在$m$使得$a_n\ge m$。  
Monotonicity and boundedness are the first two properties to check: increasing means $a_{n+1}\ge a_n$ for all sufficiently large $n$, decreasing means $a_{n+1}\le a_n$, bounded above means there exists $M$ with $a_n\le M$, and bounded below means there exists $m$ with $a_n\ge m$.

## 关键结论 / Key Results
单调收敛定理：若数列单调递增且有上界，则它收敛；若数列单调递减且有下界，则它也收敛。更精确地说，前者收敛到其上确界，后者收敛到其下确界。  
Monotone Convergence Theorem: if a sequence is increasing and bounded above, then it converges; if it is decreasing and bounded below, then it also converges. More precisely, the first converges to its supremum and the second to its infimum.

交错数列常写成$a_n=(-1)^nb_n$或$a_n=(-1)^{n+1}b_n$。像$(-1)^n$这样的序列因在$1$与$-1$之间振荡而不收敛，但若振幅趋于$0$，则往往收敛到$0$。  
Alternating sequences are often written as $a_n=(-1)^nb_n$ or $a_n=(-1)^{n+1}b_n$. A sequence like $(-1)^n$ does not converge because it oscillates between $1$ and $-1$, but if the amplitude goes to $0$, it often converges to $0$.

夹逼定理同样适用于数列：若对所有充分大的$n$都有$u_n\le a_n\le v_n$，且$\lim_{n\to\infty}u_n=\lim_{n\to\infty}v_n=L$，则$\lim_{n\to\infty}a_n=L$。  
The squeeze theorem also applies to sequences: if $u_n\le a_n\le v_n$ for all sufficiently large $n$ and $\lim_{n\to\infty}u_n=\lim_{n\to\infty}v_n=L$, then $\lim_{n\to\infty}a_n=L$.

## 例子与做题提示 / Examples and Problem-Solving Hints
典型例子是
$$
-\frac{1}{n}\le\frac{(-1)^n}{n}\le\frac{1}{n}.
$$
由于左右两边都趋于$0$，所以根据夹逼定理可得$\frac{(-1)^n}{n}\to0$。  
A standard example is
$$
-\frac{1}{n}\le\frac{(-1)^n}{n}\le\frac{1}{n}.
$$
Since both outer sequences go to $0$, the squeeze theorem gives $\frac{(-1)^n}{n}\to0$.

做题时可按这个顺序检查：先看是否单调，再看是否有界；若出现交错符号，先看绝对值是否趋于$0$；若表达式振荡但振幅缩小，则优先尝试夹逼。  
For problem solving, use this order: first test monotonicity, then boundedness; if signs alternate, check whether the absolute value goes to $0$; if the expression oscillates with shrinking amplitude, try the squeeze theorem first.
