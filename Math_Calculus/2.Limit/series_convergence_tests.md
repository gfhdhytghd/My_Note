# 无穷级数收敛判别 / Convergence Tests for Infinite Series

## 核心思路 / Core Idea
判断无穷级数$\sum a_n$是否收敛时，先排除必发散情形，再根据项的结构选择最合适的判别法。  
To determine whether an infinite series $\sum a_n$ converges, first rule out forced divergence, then choose the test that best matches the form of the terms.

## 1. 发散判别法 / Divergence Test
- 若$\lim_{n\to\infty}a_n\neq0$，则$\sum a_n$一定发散。  
  If $\lim_{n\to\infty}a_n\neq0$, then $\sum a_n$ must diverge.
- 若$\lim_{n\to\infty}a_n=0$，只能说明级数“有可能”收敛，不能直接下结论。  
  If $\lim_{n\to\infty}a_n=0$, the series only has a chance to converge; this alone is not enough.

## 2. 比较判别法 / Comparison Test
- 适用于非负项级数，通过与已知收敛性的基准级数比较判断。  
  This applies to series with nonnegative terms by comparing them with a benchmark series whose behavior is already known.
- 常见基准是$p$级数$\sum\frac{1}{n^p}$：当$p>1$时收敛，当$p\leq1$时发散。  
  A common benchmark is the $p$-series $\sum\frac{1}{n^p}$: it converges for $p>1$ and diverges for $p\leq1$.
- 若$0\leq a_n\leq b_n$且$\sum b_n$收敛，则$\sum a_n$也收敛。  
  If $0\leq a_n\leq b_n$ and $\sum b_n$ converges, then $\sum a_n$ also converges.
- 若$0\leq a_n\leq b_n$且$\sum a_n$发散，则$\sum b_n$也发散。  
  If $0\leq a_n\leq b_n$ and $\sum a_n$ diverges, then $\sum b_n$ must also diverge.

## 3. 极限比较判别法 / Limit Comparison Test
- 若$a_n,b_n>0$，且
  $$
  \lim_{n\to\infty}\frac{a_n}{b_n}=c,\quad 0<c<\infty,
  $$
  则$\sum a_n$与$\sum b_n$同收敛或同发散。  
  If $a_n,b_n>0$ and the limit above exists with $0<c<\infty$, then $\sum a_n$ and $\sum b_n$ have the same convergence behavior.
- 当$a_n$像有理函数、含对数的分式或可近似成某个$p$级数时，这个判别法通常最省力。  
  This test is often the most efficient when $a_n$ looks like a rational expression, a logarithmic fraction, or something asymptotic to a $p$-series.

## 4. 比值判别法 / Ratio Test
- 当$a_n$含有$n!$、$c^n$、幂函数连乘，或相邻项相除后能大量约分时，优先考虑比值判别法。  
  When $a_n$ contains factorials, powers like $c^n$, product-like expressions, or simplifies heavily under $\frac{a_{n+1}}{a_n}$, the ratio test is often the first choice.
- 若
  $$
  L=\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|,
  $$
  则当$L<1$时，$\sum a_n$绝对收敛；当$L>1$或$L=\infty$时，$\sum a_n$发散。  
  If
  $$
  L=\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|,
  $$
  then $\sum a_n$ converges absolutely when $L<1$, and diverges when $L>1$ or $L=\infty$.
- 若$L=1$，此判别法无效，不能据此断定级数条件收敛。  
  If $L=1$, the ratio test is inconclusive and does not imply conditional convergence.

## 5. 积分判别法 / Integral Test
- 若$a_n=f(n)$，并且$f(x)$在$x\geq1$上满足正、连续、单调递减，则
  $$
  \sum a_n\quad\text{与}\quad\int_1^\infty f(x)\,dx
  $$
  同收敛或同发散。  
  If $a_n=f(n)$ and $f(x)$ is positive, continuous, and decreasing on $x\geq1$, then the series and the improper integral either both converge or both diverge.
- 经典例子是
  $$
  \int_1^\infty\frac{1}{x^p}\,dx,
  $$
  它在$p>1$时收敛、在$p\leq1$时发散，因此$\sum\frac{1}{n^p}$也有相同结论。  
  A classic example is $\int_1^\infty\frac{1}{x^p}\,dx$, which converges for $p>1$ and diverges for $p\leq1$, so $\sum\frac{1}{n^p}$ has the same result.

## 做题流程 / Problem-Solving Workflow
1. 先算$\lim_{n\to\infty}a_n$；若极限不为$0$，直接判发散。  
   First compute $\lim_{n\to\infty}a_n$; if the limit is not $0$, the series diverges immediately.
2. 再看项的形状；若像$\frac{1}{n^p}$、$\frac{1}{n\ln n}$或有理函数，优先考虑比较判别或极限比较判别。  
   Then inspect the form; for expressions like $\frac{1}{n^p}$, $\frac{1}{n\ln n}$, or rational functions, comparison-based tests are usually best.
3. 若出现$n!$、$c^n$，或相邻项相除后能明显化简，优先尝试比值判别法。  
   If factorials, exponential terms, or strong cancellation in $\frac{a_{n+1}}{a_n}$ appear, try the ratio test first.
4. 若能自然写成正、连续、递减的$f(n)$，可转去做积分判别。  
   If the terms naturally come from a positive, continuous, decreasing function $f(n)$, the integral test is a strong option.

## 易错点 / Common Pitfall
项趋于$0$只是级数收敛的必要条件，不是充分条件；调和级数$\sum\frac{1}{n}$就是最典型的反例。  
Terms going to $0$ are necessary but not sufficient for series convergence; the harmonic series $\sum\frac{1}{n}$ is the standard counterexample.
