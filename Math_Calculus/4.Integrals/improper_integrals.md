# 反常积分 / Improper Integrals

## 什么是反常积分 / What Is an Improper Integral
当积分区间无穷，或被积函数在端点/区间内部发散时，定积分要通过极限来定义，这类积分称为反常积分。  
When the interval is infinite, or the integrand blows up at an endpoint or inside the interval, the definite integral must be defined by a limit; such integrals are called improper integrals.

### Type I：无穷区间 / Infinite Interval
若积分上限或下限是$\pm\infty$，则写成极限：
If an endpoint is $\pm\infty$, write it as a limit:
$$
\int_a^\infty f(x)\,dx=\lim_{t\to\infty}\int_a^t f(x)\,dx.
$$

### Type II：奇点 / Singularities
若$f(x)$在端点或区间内部不连续，例如分母为$0$、$\ln(0)$或出现竖直渐近线，也要用极限定义。  
If $f(x)$ is discontinuous at an endpoint or inside the interval, such as when the denominator is $0$, $\ln(0)$ appears, or there is a vertical asymptote, we also define the integral by limits.

若奇点在$x=c$，则
If the singularity is at $x=c$, then
$$
\int_a^b f(x)\,dx
=
\lim_{t\to c^-}\int_a^t f(x)\,dx
+
\lim_{t\to c^+}\int_t^b f(x)\,dx.
$$

## 计算规则 / Computation Rules
- 若不连续点在区间内部，必须拆成两段分别取极限。  
  If the discontinuity lies inside the interval, you must split the integral into two pieces and take limits separately.
- 任意一侧发散，则整个反常积分发散。  
  If either side diverges, then the whole improper integral diverges.
- 不能把左边$-\infty$与右边$+\infty$“抵消”为$0$；那仍然是发散。  
  You cannot “cancel” a left $-\infty$ with a right $+\infty$; the integral still diverges.

## 必背$p$-积分 / Essential $p$-Integrals
### 无穷区间 / Infinite Interval
$$
\int_1^\infty\frac{1}{x^p}\,dx
$$
当$p>1$时收敛，当$p\le1$时发散。  
This converges for $p>1$ and diverges for $p\le1$.

### 接近$0$ / Near Zero
$$
\int_0^1\frac{1}{x^p}\,dx
$$
当$p<1$时收敛，当$p\ge1$时发散。  
This converges for $p<1$ and diverges for $p\ge1$.

## 比较判别 / Comparison Tests
### 直接比较 / Direct Comparison
若$0\le f(x)\le g(x)$，则
If $0\le f(x)\le g(x)$, then
- 若$\int g$收敛，则$\int f$也收敛。  
  If $\int g$ converges, then $\int f$ also converges.
- 若$\int f$发散，则$\int g$也发散。  
  If $\int f$ diverges, then $\int g$ also diverges.

### 极限比较 / Limit Comparison
若
If
$$
\lim_{x\to\infty}\frac{f(x)}{g(x)}=L,\quad 0<L<\infty,
$$
则$\int f$与$\int g$有相同的敛散性；在有限奇点附近也可以作类似比较。  
then $\int f$ and $\int g$ have the same convergence behavior; a similar comparison works near a finite singularity.

## 常见题型 / Common Problem Types
1. $\int_a^\infty f(x)\,dx$或$\int_{-\infty}^b f(x)\,dx$。  
   $\int_a^\infty f(x)\,dx$ or $\int_{-\infty}^b f(x)\,dx$.
2. 长得像$\dfrac{1}{x^p}$，适合直接套$p$-积分。  
   Expressions resembling $\dfrac{1}{x^p}$, which fit the $p$-integral test.
3. 端点奇点，如$\int_0^1\dfrac{1}{x^p}\,dx$。  
   Endpoint singularities such as $\int_0^1\dfrac{1}{x^p}\,dx$.
4. 内部奇点，必须拆区间。  
   Interior singularities, where splitting is mandatory.
5. 三角函数在某点爆炸，如$\tan x,\sec x,\csc x$。  
   Trigonometric blow-ups such as $\tan x,\sec x,\csc x$.

## 易错点 / Common Pitfalls
- 忘记先写极限。  
  Forgetting to write the limiting definition first.
- 区间内部有奇点却不拆开。  
  Failing to split the interval when there is an interior singularity.
- 把“发散”误写成“等于$\infty$”。  
  Writing “equals $\infty$” instead of saying the integral diverges.
- 把$\infty-\infty$误判成可抵消。  
  Treating $\infty-\infty$ as something that can be canceled.
