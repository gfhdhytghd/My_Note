# 分部分式分解 / Partial Fraction Decomposition

## 核心思路 / Core Idea
处理有理函数积分$\int\frac{P(x)}{Q(x)}\,dx$时，目标是把复杂分式拆成若干可以直接积分的标准块。  
When integrating a rational function $\int\frac{P(x)}{Q(x)}\,dx$, the goal is to split a complicated fraction into standard pieces that can be integrated directly.

若$\deg P\ge\deg Q$，先做多项式长除，把它改写成“多项式 + 真分式”。  
If $\deg P\ge\deg Q$, first use polynomial long division to rewrite it as “polynomial + proper fraction.”

## 标准流程 / Standard Workflow
1. 若不是真分式，先长除。  
   If the fraction is not proper, perform long division first.
2. 分解$Q(x)$为线性因子与不可约二次因子。  
   Factor $Q(x)$ into linear factors and irreducible quadratic factors.
3. 按因子类型写出部分分式模板。  
   Write the partial-fraction template according to the factor types.
4. 用代入法或比较系数法求未知常数。  
   Solve for the unknown constants by substitution or coefficient matching.
5. 逐项积分并合并常数$C$。  
   Integrate term by term and combine constants into $C$.

## Case I：不重复一次因子 / Distinct Linear Factors
若分母含不同线性因子，则写成
If the denominator has distinct linear factors, write
$$
\frac{A}{x-a}+\frac{B}{x-b}+\cdots.
$$

例：
Example:
$$
\frac{x+5}{(x+1)(x+2)}=\frac{A}{x+1}+\frac{B}{x+2}.
$$
解得$A=4,\ B=-3$，所以
Solving gives $A=4,\ B=-3$, so
$$
\int\frac{x+5}{(x+1)(x+2)}\,dx
=
4\ln|x+1|-3\ln|x+2|+C.
$$

## Case II：重复一次因子 / Repeated Linear Factors
若有$(x-a)^n$，必须从一次写到$n$次：
If $(x-a)^n$ appears, include every power from $1$ to $n$:
$$
\frac{A_1}{x-a}+\frac{A_2}{(x-a)^2}+\cdots+\frac{A_n}{(x-a)^n}.
$$

例：
Example:
$$
\frac{1}{x(x+1)^2}=\frac{A}{x}+\frac{B}{x+1}+\frac{C}{(x+1)^2}.
$$
解得$A=1,\ B=-1,\ C=-1$，因此
Solving gives $A=1,\ B=-1,\ C=-1$, hence
$$
\int\frac{1}{x(x+1)^2}\,dx
=
\ln|x|-\ln|x+1|+\frac{1}{x+1}+C.
$$

## Case III：不重复不可约二次因子 / Distinct Irreducible Quadratics
每个不可约二次因子$(x^2+bx+c)$都要配一次分子$(Ax+B)$。  
Each irreducible quadratic factor $(x^2+bx+c)$ must be paired with a linear numerator $(Ax+B)$.

例：
Example:
$$
\frac{3x+5}{(x^2+1)(x^2+4)}
=
\frac{Ax+B}{x^2+1}+\frac{Cx+D}{x^2+4}.
$$
这类积分通常会同时出现$\ln$项与$\arctan$项。  
This type of decomposition typically produces both logarithmic and arctangent terms.

## Case IV：重复不可约二次因子 / Repeated Irreducible Quadratics
若有$(x^2+bx+c)^n$，则写成
If $(x^2+bx+c)^n$ appears, write
$$
\frac{A_1x+B_1}{x^2+bx+c}
+
\frac{A_2x+B_2}{(x^2+bx+c)^2}
+
\cdots
+
\frac{A_nx+B_n}{(x^2+bx+c)^n}.
$$

例如
For example,
$$
\int\frac{1}{(x^2+1)^2}\,dx
=
\frac{x}{2(x^2+1)}+\frac{1}{2}\arctan x+C.
$$
这说明重复二次因子常给出“有理项 + 反三角项”的组合。  
This shows that repeated quadratic factors often produce a combination of a rational term and an inverse-trig term.

## 为什么最后常见$\ln,\arctan,\text{幂函数}$ / Why $\ln$, $\arctan$, and Power Terms Appear
- $\int\frac{1}{x-a}\,dx=\ln|x-a|+C$。  
  $\int\frac{1}{x-a}\,dx=\ln|x-a|+C$.
- $\int\frac{1}{x^2+a^2}\,dx=\frac{1}{a}\arctan\left(\frac{x}{a}\right)+C$。  
  $\int\frac{1}{x^2+a^2}\,dx=\frac{1}{a}\arctan\left(\frac{x}{a}\right)+C$.
- $\int(x-a)^{-n}\,dx$（$n\neq1$）会给出幂函数型结果。  
  $\int(x-a)^{-n}\,dx$ with $n\neq1$ gives a power-type antiderivative.

所以分部分式的本质，就是把复杂有理函数拆到这些“标准可积块”上。  
So the essence of partial fractions is reducing a complicated rational function to these standard integrable pieces.
