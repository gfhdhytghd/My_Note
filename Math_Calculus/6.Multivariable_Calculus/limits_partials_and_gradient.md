# 多元函数的极限、偏导与梯度 / Multivariable Limits, Partial Derivatives, and Gradients

## 三维函数的极限 / Limits of Functions of Three Variables

对于三元函数 $f(x,y,z)$，点 $(x,y,z)$ 趋近于 $(a,b,c)$ 时，如果无论沿哪一条路径接近，函数值都趋近于同一个 $L$，则记为 $\lim_{(x,y,z)\to(a,b,c)}f(x,y,z)=L$。这里的距离可以写成 $r=\sqrt{(x-a)^2+(y-b)^2+(z-c)^2}$。 / For a function of three variables $f(x,y,z)$, if the function approaches the same value $L$ along every path toward $(a,b,c)$, then $\lim_{(x,y,z)\to(a,b,c)}f(x,y,z)=L$. The distance to the target point is $r=\sqrt{(x-a)^2+(y-b)^2+(z-c)^2}$.

- **路径检验 / Path test：** 若找到两条路径得到不同的极限值，则三维极限不存在；但沿若干条路径得到相同结果，不能单独证明极限存在。 / If two paths produce different limiting values, the three-dimensional limit does not exist; matching values along several paths alone cannot prove existence.
- **夹逼法 / Squeeze method：** 若 $|f(x,y,z)|\leq g(x,y,z)$ 且 $g(x,y,z)\to0$，则 $f(x,y,z)\to0$。例如 $\left|\frac{xyz}{x^2+y^2+z^2}\right|\leq\frac{r^3}{3r^2}=\frac r3\to0$，所以 $\displaystyle\lim_{(x,y,z)\to(0,0,0)}\frac{xyz}{x^2+y^2+z^2}=0$。 / If $|f(x,y,z)|\leq g(x,y,z)$ and $g(x,y,z)\to0$, then $f(x,y,z)\to0$. For example, the limit at the origin of $\frac{xyz}{x^2+y^2+z^2}$ is $0$.

若分母在目标点不为零，通常可以直接代入；若分母为零，则应优先尝试因式分解、夹逼或路径检验，而不能只沿 $x$ 轴、$y$ 轴和 $z$ 轴判断。 / If the denominator is nonzero at the target point, direct substitution usually works. If it is zero, try factoring, squeezing, or path tests; checking only the three coordinate axes is not sufficient.

## 三元函数的偏导与梯度 / Partial Derivatives and the Gradient

对 $f(x,y,z)$ 求偏导时，只改变一个变量，并把另外两个变量视为常数：$f_x=\frac{\partial f}{\partial x}$、$f_y=\frac{\partial f}{\partial y}$、$f_z=\frac{\partial f}{\partial z}$。梯度是由三个偏导组成的向量：$\nabla f=\langle f_x,f_y,f_z\rangle$。 / To find a partial derivative of $f(x,y,z)$, vary one variable while treating the other two as constants. The gradient is $\nabla f=\langle f_x,f_y,f_z\rangle$.

例：若 $f(x,y,z)=x^2y+\sin z$，则 $f_x=2xy$、$f_y=x^2$、$f_z=\cos z$，因此 $\nabla f=\langle2xy,x^2,\cos z\rangle$。在点 $(1,2,0)$，$\nabla f(1,2,0)=\langle4,1,1\rangle$。 / Example: If $f(x,y,z)=x^2y+\sin z$, then $f_x=2xy$, $f_y=x^2$, and $f_z=\cos z$, so $\nabla f=\langle2xy,x^2,\cos z\rangle$. At $(1,2,0)$, $\nabla f(1,2,0)=\langle4,1,1\rangle$.

沿单位方向向量 $\mathbf u$ 的方向导数为 $D_{\mathbf u}f=\nabla f\cdot\mathbf u$。梯度指向函数增长最快的方向，最大增长率为 $\|\nabla f\|$；梯度同时垂直于等值面 $f(x,y,z)=k$。 / The directional derivative in the unit direction $\mathbf u$ is $D_{\mathbf u}f=\nabla f\cdot\mathbf u$. The gradient points in the direction of greatest increase, whose rate is $\|\nabla f\|$; it is also perpendicular to the level surface $f(x,y,z)=k$.

若函数在点附近可微，则三维线性近似为 $f(a+\Delta x,b+\Delta y,c+\Delta z)\approx f(a,b,c)+f_x\Delta x+f_y\Delta y+f_z\Delta z$。可微性比各偏导存在更强：偏导存在不一定保证函数可微。 / If the function is differentiable near a point, its three-dimensional linear approximation is $f(a+\Delta x,b+\Delta y,c+\Delta z)\approx f(a,b,c)+f_x\Delta x+f_y\Delta y+f_z\Delta z$. Differentiability is stronger than the existence of partial derivatives: partial derivatives alone do not guarantee differentiability.
