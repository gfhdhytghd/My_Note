# 基与维数 / Basis and Dimension

## 定义与核心直觉 / Definitions and Core Intuition
向量空间的一组基（basis）是一个既线性无关、又能张成整个空间的向量集合；因此空间中的每个向量都能唯一写成基向量的线性组合。  
A basis of a vector space is a set of vectors that is both linearly independent and spanning; therefore every vector in the space can be written uniquely as a linear combination of basis vectors.

维数（dimension）是一组基中向量的个数，也可以理解为这个空间的自由度。这个概念不仅适用于$\mathbb{R}^n$，也适用于矩阵空间、多项式空间等抽象向量空间。  
The dimension is the number of vectors in a basis, which can also be understood as the degrees of freedom of the space. This applies not only to $\mathbb{R}^n$ but also to matrix spaces, polynomial spaces, and other abstract vector spaces.

## 典型例子 / Standard Examples
在$\mathbb{R}^3$中，标准基是
$$
\left\{
\begin{bmatrix}1\\0\\0\end{bmatrix},
\begin{bmatrix}0\\1\\0\end{bmatrix},
\begin{bmatrix}0\\0\\1\end{bmatrix}
\right\},
$$
因此$\dim(\mathbb{R}^3)=3$。任意向量$\begin{bmatrix}3\\4\\5\end{bmatrix}$都可唯一写成这组三个向量的线性组合。  
In $\mathbb{R}^3$, the standard basis is
$$
\left\{
\begin{bmatrix}1\\0\\0\end{bmatrix},
\begin{bmatrix}0\\1\\0\end{bmatrix},
\begin{bmatrix}0\\0\\1\end{bmatrix}
\right\},
$$
so $\dim(\mathbb{R}^3)=3$. Any vector such as $\begin{bmatrix}3\\4\\5\end{bmatrix}$ can be written uniquely as a linear combination of these three vectors.

在矩阵空间$M_{2\times2}(\mathbb{R})$中，可取四个矩阵单位作为一组自然基，因此$\dim(M_{2\times2}(\mathbb{R}))=4$。在多项式空间$P_2(\mathbb{R})=\{ax^2+bx+c\mid a,b,c\in\mathbb{R}\}$中，一组标准基是$\{1,x,x^2\}$，所以维数为$3$。  
In the matrix space $M_{2\times2}(\mathbb{R})$, the four matrix units form a natural basis, so $\dim(M_{2\times2}(\mathbb{R}))=4$. In the polynomial space $P_2(\mathbb{R})=\{ax^2+bx+c\mid a,b,c\in\mathbb{R}\}$, a standard basis is $\{1,x,x^2\}$, so the dimension is $3$.

对称矩阵空间$\operatorname{Sym}_{n\times n}(\mathbb{R})$也是典型例子。其一组自然基可写为对角矩阵单位$E_{11},\dots,E_{nn}$与成对的$E_{ij}+E_{ji}$（$1\le i<j\le n$），因此
$$
\dim(\operatorname{Sym}_{n\times n}(\mathbb{R}))=\frac{n(n+1)}{2}.
$$
The symmetric matrix space $\operatorname{Sym}_{n\times n}(\mathbb{R})$ is another standard example. A natural basis is given by the diagonal units $E_{11},\dots,E_{nn}$ together with the paired matrices $E_{ij}+E_{ji}$ for $1\le i<j\le n$, so
$$
\dim(\operatorname{Sym}_{n\times n}(\mathbb{R}))=\frac{n(n+1)}{2}.
$$

## 子空间辨析 / Subspace Clarification
$\mathbb{R}^2$ 本身不是$\mathbb{R}^3$的子空间，因为$\mathbb{R}^2$中的元素是有序对$(x,y)$，而$\mathbb{R}^3$中的元素是有序三元组$(x,y,z)$，两者不是同一个母集合中的元素。  
$\mathbb{R}^2$ itself is not a subspace of $\mathbb{R}^3$ because elements of $\mathbb{R}^2$ are ordered pairs $(x,y)$, while elements of $\mathbb{R}^3$ are ordered triples $(x,y,z)$, so they are not elements of the same ambient set.

但$\mathbb{R}^3$中确实存在与$\mathbb{R}^2$同构的二维子空间，例如
$$
W=\{(x,y,0)\mid x,y\in\mathbb{R}\},
$$
它包含零向量，并且对加法与数乘封闭。  
However, $\mathbb{R}^3$ does contain two-dimensional subspaces isomorphic to $\mathbb{R}^2$, for example
$$
W=\{(x,y,0)\mid x,y\in\mathbb{R}\},
$$
which contains the zero vector and is closed under addition and scalar multiplication.

## 课堂小结 / Quick Takeaway
- 基 = 线性无关 + 张成整个空间。  
  Basis = linear independence + spanning the whole space.
- 维数 = 基向量个数 = 自由度。  
  Dimension = number of basis vectors = degrees of freedom.
- 基与维数适用于列向量空间、矩阵空间、多项式空间等多种对象。  
  Basis and dimension apply to column-vector spaces, matrix spaces, polynomial spaces, and more.
