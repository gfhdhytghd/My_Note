# 线性变换与标准矩阵 / Linear Transformations and Standard Matrix

## 定义与直觉 / Definition & Intuition
- 标准矩阵把“线性变换对标准基向量的输出”按列拼成矩阵，所以知道了$T(\mathbf e_1),\dots,T(\mathbf e_n)$就知道了整个$T$。  
  The standard matrix stacks the images of standard basis vectors as columns, so knowing $T(\mathbf e_1),\dots,T(\mathbf e_n)$ determines the whole linear map $T$.

- 若$T:\mathbb{R}^n\to\mathbb{R}^m$是线性变换，存在矩阵$A\in\mathbb{R}^{m\times n}$使得对任意$\mathbf x$都有$T(\mathbf x)=A\mathbf x$。  
  If $T:\mathbb{R}^n\to\mathbb{R}^m$ is linear, there exists $A\in\mathbb{R}^{m\times n}$ such that $T(\mathbf x)=A\mathbf x$ for all $\mathbf x$.

## 关键结论 / Key Results
- 标准矩阵 / Standard matrix：若$A$是$T$的标准矩阵，则  
  If $A$ is the standard matrix of $T$, then
  $$
  A=[T(\mathbf e_1)\;T(\mathbf e_2)\;\dots\;T(\mathbf e_n)].
  $$

- 单射与满射（用$A$判别）/ Injective & surjective (via $A$)
  - 定义 / Definitions：  
    单射（one-to-one/injective）：$T(\mathbf x_1)=T(\mathbf x_2)\Rightarrow\mathbf x_1=\mathbf x_2$（等价于$T(\mathbf x)=\mathbf0$只有平凡解$\mathbf x=\mathbf0$）。  
    Injective: $T(\mathbf x_1)=T(\mathbf x_2)\Rightarrow\mathbf x_1=\mathbf x_2$ (equivalently, $T(\mathbf x)=\mathbf0$ has only the trivial solution).
    
    满射（onto/surjective）：对任意$\mathbf b\in\mathbb{R}^m$，都存在$\mathbf x\in\mathbb{R}^n$使$T(\mathbf x)=\mathbf b$（等价于$A\mathbf x=\mathbf b$对所有$\mathbf b$可解）。  
    Surjective: for every $\mathbf b\in\mathbb{R}^m$ there exists $\mathbf x\in\mathbb{R}^n$ with $T(\mathbf x)=\mathbf b$ (equivalently, $A\mathbf x=\mathbf b$ is solvable for all $\mathbf b$).

  - 核与像 / Kernel & range：对$T(\mathbf x)=A\mathbf x$，  
    For $T(\mathbf x)=A\mathbf x$,
    $$
    \ker(T)=\{\mathbf x:A\mathbf x=\mathbf0\},\quad \operatorname{range}(T)=\{A\mathbf x:\mathbf x\in\mathbb{R}^n\}.
    $$
    所以“单射$\Leftrightarrow\ker(T)=\{\mathbf0\}$”，“满射$\Leftrightarrow\operatorname{range}(T)=\mathbb{R}^m$”。  
    So injective $\Leftrightarrow\ker(T)=\{\mathbf0\}$, and surjective $\Leftrightarrow\operatorname{range}(T)=\mathbb{R}^m$.

  - 主元判别 / Pivot criteria（看$rref(A)$）：  
    Injective $\Leftrightarrow$ 每一列都有主元（pivot in every column）$\Leftrightarrow\operatorname{rank}(A)=n$。  
    Surjective $\Leftrightarrow$ 每一行都有主元（pivot in every row）$\Leftrightarrow\operatorname{rank}(A)=m$。

  - 维度快速判断 / Dimension quick checks：  
    若$n>m$（从$\mathbb{R}^n$到更低维$\mathbb{R}^m$），不可能单射；若$n<m$，不可能满射。  
    If $n>m$, $T:\mathbb{R}^n\to\mathbb{R}^m$ cannot be injective; if $n<m$, it cannot be surjective.

- 维度直觉 / Dimension intuition：若$T:\mathbb{R}^2\to\mathbb{R}^3$是线性变换，像集$\operatorname{range}(T)$是$\mathbb{R}^3$中的一个过原点的子空间（常见是平面或直线），因此通常不可能等于整个$\mathbb{R}^3$（不满射）。  
  For a linear map $T:\mathbb{R}^2\to\mathbb{R}^3$, the range is a subspace through the origin (often a plane or a line), so it typically cannot be all of $\mathbb{R}^3$ (not onto).

- 等维情形 / Equal-dimension case：当$T:\mathbb{R}^n\to\mathbb{R}^n$时，线性变换满足“单射$\Leftrightarrow$满射$\Leftrightarrow$可逆”。  
  For $T:\mathbb{R}^n\to\mathbb{R}^n$, we have injective $\Leftrightarrow$ surjective $\Leftrightarrow$ invertible.

## 例子与练习 / Examples & Exercises
- 例子 / Example：设$T:\mathbb{R}^2\to\mathbb{R}^2$，$T(x,y)=(2x+y,x-3y)$。  
  Let $T:\mathbb{R}^2\to\mathbb{R}^2$ be $T(x,y)=(2x+y,x-3y)$.
  $$
  T(\mathbf e_1)=T(1,0)=(2,1),\quad T(\mathbf e_2)=T(0,1)=(1,-3),
  $$
  因此标准矩阵为$A=\begin{bmatrix}2&1\\1&-3\end{bmatrix}$，且对任意$\mathbf v=(x,y)$有$T(\mathbf v)=A\mathbf v$。  
  So the standard matrix is $A=\begin{bmatrix}2&1\\1&-3\end{bmatrix}$ and $T(\mathbf v)=A\mathbf v$ for any $\mathbf v=(x,y)$.

- 快算 / Quick check：取$\mathbf v=(4,5)$，则  
  Take $\mathbf v=(4,5)$, then
  $$
  T(4,5)=(13,-11),\quad A\begin{bmatrix}4\\5\end{bmatrix}=\begin{bmatrix}13\\-11\end{bmatrix}.
  $$

- 单射/满射检查 / Injective/surjective check（本例）：  
  $\det(A)=2(-3)-1\cdot1=-7\neq0$，所以$A$可逆，从而$T$既单射又满射（双射）。  
  Since $\det(A)=-7\neq0$, $A$ is invertible, so $T$ is both injective and surjective (bijective).
