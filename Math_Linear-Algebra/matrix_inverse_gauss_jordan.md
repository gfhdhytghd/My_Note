# 矩阵求逆与高斯-约旦 / Matrix Inverse via Gauss-Jordan

## 核心算法 / Core Algorithm
若$A$可逆，增广矩阵法为
If $A$ is invertible, use the augmented algorithm
$$
[A\mid I]\xrightarrow{\text{row reduction}}[I\mid A^{-1}].
$$
左块化成单位矩阵后，右块就是逆矩阵。  
When the left block becomes identity, the right block is the inverse.

## 可逆判别 / Invertibility Criteria
对$n\times n$方阵$A$，下列等价：  
For an $n\times n$ matrix $A$, the following are equivalent:
- $A$可逆。 / $A$ is invertible.
- $\det(A)\neq0$。 / $\det(A)\neq0$.
- $\mathrm{rank}(A)=n$。 / $\mathrm{rank}(A)=n$.
- 列向量线性无关。 / Columns are linearly independent.

## 2x2快速公式 / 2x2 Closed Form
$$
A=\begin{pmatrix}a&b\\ c&d\end{pmatrix},\quad
A^{-1}=\frac{1}{ad-bc}\begin{pmatrix}d&-b\\ -c&a\end{pmatrix},\quad ad-bc\neq0.
$$
这个公式可由$[A\mid I]\to[I\mid A^{-1}]$推导得到。  
This formula is derived directly from $[A\mid I]\to[I\mid A^{-1}]$.

## 常用性质 / Common Properties
- $(AB)^{-1}=B^{-1}A^{-1}$
- $(A^T)^{-1}=(A^{-1})^T$
- $\det(A^{-1})=1/\det(A)$
- 解线性方程：若$A\mathbf x=\mathbf b$且$A$可逆，则$\mathbf x=A^{-1}\mathbf b$。  
  Solving systems: if $A\mathbf x=\mathbf b$ and $A$ is invertible, then $\mathbf x=A^{-1}\mathbf b$.
