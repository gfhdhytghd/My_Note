# 矩阵乘法与复合顺序 / Matrix Multiplication and Composition Order

## 定义与直觉 / Definition & Intuition
- 矩阵乘法描述“先做一个线性变换、再做另一个线性变换”的结果；顺序很重要，因为一般$AB\neq BA$。  
  Matrix multiplication models successive linear maps; order matters because in general $AB\neq BA$.

## 关键结论 / Key Results
- 维度匹配 / Dimension match：若$A\in\mathbb{R}^{m\times n}$，$B\in\mathbb{R}^{n\times p}$，则$AB$有定义且$AB\in\mathbb{R}^{m\times p}$。  
  If $A\in\mathbb{R}^{m\times n}$ and $B\in\mathbb{R}^{n\times p}$, then $AB$ is defined and $AB\in\mathbb{R}^{m\times p}$.

- 元素公式 / Entrywise formula：
  $$
  (AB)_{ij}=\sum_{k=1}^na_{ik}b_{kj}.
  $$

- 列视角 / Column view：把$B$写成列块$B=[\mathbf b_1,\dots,\mathbf b_p]$，则  
  Writing $B$ in columns $B=[\mathbf b_1,\dots,\mathbf b_p]$, we have
  $$
  AB=[A\mathbf b_1,\dots,A\mathbf b_p].
  $$

- 复合顺序 / Composition order：若$T(\mathbf x)=B\mathbf x$且$S(\mathbf y)=A\mathbf y$，则  
  If $T(\mathbf x)=B\mathbf x$ and $S(\mathbf y)=A\mathbf y$, then
  $$
  (S\circ T)(\mathbf x)=A(B\mathbf x)=(AB)\mathbf x.
  $$
  所以“先作用的矩阵写在右边、后作用的写在左边”。  
  So the matrix that acts first is written on the right.

## 例子与练习 / Examples & Exercises
- 例子 / Example：设$A=\begin{bmatrix}0&-1\\1&0\end{bmatrix}$（旋转$90^\circ$），$B=\begin{bmatrix}2&0\\0&1\end{bmatrix}$（$x$方向拉伸）。  
  Let $A=\begin{bmatrix}0&-1\\1&0\end{bmatrix}$ (rotate $90^\circ$) and $B=\begin{bmatrix}2&0\\0&1\end{bmatrix}$ (stretch in $x$).
  先旋转后拉伸对应$BA$，先拉伸后旋转对应$AB$；它们一般不相等。  
  Rotate then stretch gives $BA$, stretch then rotate gives $AB$; they are generally different.
