# 列空间、零空间与解集 / Column Space, Null Space, and Solution Sets

## 定义 / Definitions
- 零空间$\mathcal N(A)$（或$Nul(A)$）是齐次方程$A\mathbf x=\mathbf0$的解集。  
  The null space $\mathcal N(A)$ (or $Nul(A)$) is the solution set of the homogeneous equation $A\mathbf x=\mathbf0$.
- 列空间$\mathrm{Col}(A)$是矩阵$A$所有列向量的线性组合构成的集合。  
  The column space $\mathrm{Col}(A)$ is the set of all linear combinations of the columns of $A$.

## 为什么它们是子空间 / Why They Are Subspaces
- 零空间一定包含$\mathbf0$，因为$A\mathbf0=\mathbf0$；若$\mathbf v,\mathbf w\in\mathcal N(A)$，则$A(\mathbf v+\mathbf w)=A\mathbf v+A\mathbf w=\mathbf0$，且$A(c\mathbf v)=cA\mathbf v=\mathbf0$，所以零空间对加法与数乘封闭。  
  The null space contains $\mathbf0$ because $A\mathbf0=\mathbf0$; if $\mathbf v,\mathbf w\in\mathcal N(A)$, then $A(\mathbf v+\mathbf w)=A\mathbf v+A\mathbf w=\mathbf0$ and $A(c\mathbf v)=cA\mathbf v=\mathbf0$, so it is closed under addition and scalar multiplication.
- 列空间是列向量的$\operatorname{span}$，而任何$\operatorname{span}$都是子空间，因此$\mathrm{Col}(A)$是$\mathbb{R}^m$的子空间。  
  The column space is a span of column vectors, and every span is a subspace, so $\mathrm{Col}(A)$ is a subspace of $\mathbb{R}^m$.

## 如何找$\mathcal N(A)$的基 / How to Find a Basis for $\mathcal N(A)$
1. 先把齐次系统$A\mathbf x=\mathbf0$行化简，并写成参数形式。  
   Row-reduce the homogeneous system $A\mathbf x=\mathbf0$ and write the solution in parametric form.
2. 把每个自由变量对应的一组方向向量抽出来，组成零空间的一组基。  
   Extract the direction vector attached to each free variable; those vectors form a basis for the null space.
3. 零空间的维数称为零度$Nullity(A)$，它等于自由变量的个数。  
   The dimension of the null space is called $Nullity(A)$, and it equals the number of free variables.

## 秩-零度定理 / Rank-Nullity Theorem
若$A$是$m\times n$矩阵，则
If $A$ is an $m\times n$ matrix, then
$$
\operatorname{rank}(A)+\operatorname{nullity}(A)=n.
$$
这里$\operatorname{rank}(A)$是主元列的个数，$\operatorname{nullity}(A)$是自由变量的个数；它们加起来正好等于列数$n$。  
Here $\operatorname{rank}(A)$ is the number of pivot columns and $\operatorname{nullity}(A)$ is the number of free variables; together they add up to the total number of columns $n$.

## 两个核心问题 / Two Core Questions
- 给定$A$，哪些$\mathbf b$可达？答案是$\mathbf b\in\mathrm{Col}(A)$。  
  Given $A$, which $\mathbf b$ are attainable? Exactly those in $\mathrm{Col}(A)$.
- 给定$A,\mathbf b$，哪些$\mathbf x$满足$A\mathbf x=\mathbf b$？答案由相容性与自由变量决定。  
  Given $A,\mathbf b$, which $\mathbf x$ solve $A\mathbf x=\mathbf b$? It is determined by consistency and free variables.

## 解的三种情形 / Three Solution Cases
- 无解：行化简出现$[0\ \cdots\ 0\mid c]$且$c\neq0$。  
  No solution: row reduction yields $[0\ \cdots\ 0\mid c]$ with $c\neq0$.
- 唯一解：每个未知量列都是主元列（无自由变量）。  
  Unique solution: every variable column is a pivot column (no free variables).
- 无穷多解：存在自由变量，解集可参数化。  
  Infinitely many solutions: free variables exist, so the set is parameterized.

参数形式：
Parametric form:
$$
\mathbf x=\mathbf x_p+t_1\mathbf v_1+\cdots+t_k\mathbf v_k,
$$
其中$\mathbf x_p$是特解，$\mathbf v_i$来自齐次方程$A\mathbf x=\mathbf0$的零空间方向。  
Here $\mathbf x_p$ is a particular solution, and $\mathbf v_i$ are null-space directions from $A\mathbf x=\mathbf0$.

## 列空间、秩与零空间维数 / Column Space, Rank, and Nullity
- $\dim(\mathrm{Col}(A))=\mathrm{rank}(A)$（主元个数）。  
  $\dim(\mathrm{Col}(A))=\mathrm{rank}(A)$ (number of pivots).
- 自由变量个数$=n-\mathrm{rank}(A)=\dim(\mathcal N(A))$。  
  Number of free variables $=n-\mathrm{rank}(A)=\dim(\mathcal N(A))$.
- 齐次系统$A\mathbf x=\mathbf0$的解集就是$\mathcal N(A)$，一定经过原点。  
  The solution set of homogeneous $A\mathbf x=\mathbf0$ is exactly $\mathcal N(A)$ and passes through the origin.
- 非齐次系统（若相容）是零空间的平移，一般不过原点。  
  A non-homogeneous consistent system is a translation of the null space and usually does not pass through the origin.
