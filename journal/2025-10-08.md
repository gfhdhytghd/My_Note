Chapter 9：long run cost
long-run is defined by a time frame where fixed costs (big machines that cost high) become variable cost.

## 长期成本 / Long-Run Costs

- 提炼为 / Extracted to：card![[Economics/6.Production_Costs/long_run_costs]]

- 定义 / Definition：长期是指固定要素（如工厂、机器）可以调整的时间跨度；所有成本均视为可变成本。/ Long run is a time horizon in which fixed inputs (e.g., plants, machines) can be adjusted; all costs are variable.
- 长期平均总成本 / Long-Run ATC (LRATC)：在不同规模下的最低平均成本包络，刻画规模与单位成本的关系。/ LRATC is the lower envelope of short-run ATCs across plant sizes, mapping scale to unit cost.
- 规模经济 / Economies of Scale（增加规模报酬）：等比例扩大所有投入（L, K）使$LRATC$下降。/ Scaling all inputs (L, K) proportionally lowers $LRATC$ (increasing returns to scale).
- 规模不经济 / Diseconomies of Scale（递减规模报酬）：等比例扩大所有投入使$LRATC$上升。/ Scaling all inputs proportionally raises $LRATC$ (decreasing returns to scale).

- 下包络关系 / Lower Envelope：$LRATC$ 是一族短期平均总成本曲线 $SRATC$ 的“下包络”，在每个产量 $Q$ 处等于可选厂房规模中最低的 $SRATC$。/ $LRATC$ is the lower envelope of the family of $SRATC$ curves; at each quantity $Q$ it equals the minimum attainable $SRATC$ across plant sizes.
- 短期约束 / Short Run Constraint：短期内固定成本既定，企业只能在给定的一条 $SRATC$ 上调整产量；相当于“被固定成本困住”。/ In the short run, fixed costs are committed, so the firm moves along a single $SRATC$ — it is stuck with that plant.
- 长期选择 / Long Run Choice：长期可在不同厂房/规模之间选择，因此每个 $Q$ 可挑选成本最低的 $SRATC$，从而形成 $LRATC$。/ In the long run, the firm can choose among plant sizes (SRATCs), picking the lowest cost for each $Q$, which traces out the $LRATC$.
