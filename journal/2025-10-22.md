## Economics / 经济学

## Chapter 14: Oligopoly and Strategic Behavior / 第14章：寡头与战略行为

### Market Structure Comparison / 市场结构比较

|Perfect Competition / 完全竞争|Oligopoly / 寡头|Monopoly / 垄断|
|-|-|-|
|Many sellers / 众多卖方|A few sellers / 少数卖方|One seller / 单一卖方|
|Identical products / 同质产品|Differentiated products / 差异化产品|A unique product (no close substitutes) / 独特产品（无近似替代品）|
|Free entry/exit / 自由进出|Significant barriers to entry / 显著进入壁垒|Very high barriers to entry / 极高进入壁垒|

### Key Concepts / 核心概念

- Examples: Smartphones, Airlines, Lowe's & Home Depot → **oligopolies** / 例子：智能手机、航空业、Lowe's 和 Home Depot → **寡头**
- Firms in oligopolies react strategically to changes in **price** and **output** / 寡头中的企业会对**价格**与**产量**变化进行**战略性反应**
- **Game Theory**: Economic study of how agents interact in strategic situations / **博弈论**：研究主体在战略情境中如何互动的经济学
- Examples: Oligopoly, War, Chess, Strategic communication / 例子：寡头、战争、国际象棋、战略性沟通

### Game Components / 博弈要素

- A game consists of three things: **players (firms), strategies (quantity produced), payoffs (profit)** / 一个博弈由三要素构成：**参与者（企业）、策略（产量）、收益（利润）**

#### Detailed Components / 详细要素

- **Players**: Must be two or more / **参与者**：至少两名

- **Strategies**: A completely contingent plan of action. Payoffs depend on all players' strategies / **策略**：完全的行动计划。收益取决于所有参与者的策略
  - In this case: Can think of a strategy as the actions of players / 在此情况下：可将策略视为参与者的行动
  - Note: If you take more advanced game theory, this simplified definition will be incorrect / 注意：如果学习更高级的博弈论，这个简化定义将不正确
- **Payoffs**: Outcomes, typically represented by "utility" (how happy someone is) / **收益**：结果，通常以“效用”度量（反映满意度/偏好）。

## 企业竞争博弈示例 / Example: Firm Competition Game (oligopoly)

**Players:** Firm 1 (row player) and Firm 2 (column player) / **参与者：** 企业1（行玩家）与企业2（列玩家）
**Strategies:** High output, Low output / **策略：** 高产量、低产量
**Payoffs in boxes:** first number = Firm 1's payoff; second number = Firm 2's payoff / **矩阵中的收益：** 第一个数=企业1；第二个数=企业2。

|                         | **Firm 2: High Output** | **Firm 2: Low Output** |
| ----------------------- | ----------------------- | ---------------------- |
| **Firm 1: High Output** | (1, 1)                  | (15, −5)               |
| **Firm 1: Low Output**  | (−5, 15)                | (10, 10)               |

---

This is an example of a matrix (strategic-form) game. Both players choose simultaneously. / 这是一个矩阵（战略式）博弈的示例，双方同时选择。

**Analysis / 分析：** If both choose low output, they mimic a monopoly and split profits. If one chooses high output while the other chooses low, the high-output firm earns more because the price remains relatively high. If both choose high output, price and profits are lower than when both choose low output.

#### Predicting Play in Games / 博弈的行为预测
**Dominant Strategy / 占优策略：** A strategy that yields the best outcome for a player regardless of what others play. / 不论他人如何行动都能带来最佳结果的策略。
Note / 注意：A dominant strategy need not maximize total (joint) payoffs. / 占优策略不一定带来整体最优。
Example / 示例：For either firm, high output is the dominant strategy. / 对两家企业，高产量是占优策略。

**Nash Equilibrium / 纳什均衡：** A strategy profile such that, given others' strategies, no player can unilaterally deviate and do better. / 在既定他人策略下，没有参与者能通过单方面偏离而使自身更好。
In this game / 在此博弈中：Both choosing High Output is the unique Nash equilibrium. / 双方选择高产量是唯一的纳什均衡。

**Alternative Definition / 等价定义：** A Nash equilibrium is where both players best respond to each other. / 纳什均衡可表述为：双方相互给出最优回应（彼此对彼此的最优反应）。

**Stability Note / 稳定性说明：** A Nash equilibrium is a stable point; given others' strategies, no profitable unilateral deviation exists. / 纳什均衡是稳定点：在他人策略既定时不存在单方有利的偏离。

**Notation Note / 书写说明：** Use strategies to describe the Nash equilibrium, not payoffs or profits. Example: (High, High). / 书写纳什均衡请用“策略”而非“收益/利润”来描述，例如：(高产量, 高产量)。
