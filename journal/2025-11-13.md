# Chemistry

## 氧化态要点 / Oxidation State Essentials

- 定义 / Definition: 氧化态（氧化数）是假想将共价键电子全部判给电负性更大的原子后，各原子应带的电荷数；用于氧化还原计账，并不等于实际电荷分布  
  Oxidation state is the hypothetical charge when all bonding electrons are assigned to the more electronegative atom; a bookkeeping tool for redox, not real charge distribution
- 对比形式电荷 / Versus Formal Charge: 形式电荷等分共价电子（FC = 价电子 − 非键电子 − 成键电子/2）；氧化态按电负性全判给  
  Formal charge splits bonding electrons equally (FC = valence − nonbonding − bonding/2); OS assigns all to the more electronegative atom
- 基本规则 / Core Rules: 单质=0；单原子离子=离子电荷；F=−1；O通常=−2（过氧=−1，超氧=−1/2，OF₂中O=+2）；H与非金属=+1，与金属=−1；碱金属=+1，碱土=+2；分子和=0，多原子离子和=离子电荷  
  Basics: elements=0; monatomic ions=ion charge; F=−1; O usually −2 (peroxide −1, superoxide −1/2, O=+2 in OF₂); H +1 with nonmetals, −1 with metals; group 1 +1, group 2 +2; sum=0 in molecules, = net charge in ions
- 常见示例 / Examples: H₂O：H=+1, O=−2；CO₂：C=+4；NH₄⁺：N=−3；Fe₂O₃：Fe=+3；H₂O₂：O=−1；OF₂：O=+2；KMnO₄：Mn=+7  
  H₂O: H +1, O −2; CO₂: C +4; NH₄⁺: N −3; Fe₂O₃: Fe +3; H₂O₂: O −1; OF₂: O +2; KMnO₄: Mn +7
- 过渡金属 / Transition Metals: 常具多氧化态（如 Fe +2/+3，Cu +1/+2，Mn +2/+4/+7），与配体和晶体场相关  
  Often multiple OS (e.g., Fe +2/+3, Cu +1/+2, Mn +2/+4/+7), influenced by ligand/crystal field
- 与极性、电负性关系 / Links: OS 源自电负性极限假设；实际偶极与几何相关，参见 [[Chemistry/4.Chemical_Bonds/electronegativity_and_bond_types]] 与 [[Chemistry/4.Chemical_Bonds/bond_properties]]  
  OS derives from EN limit; actual dipole depends on geometry, see [[Chemistry/4.Chemical_Bonds/electronegativity_and_bond_types]] and [[Chemistry/4.Chemical_Bonds/bond_properties]]
- 参考 / Reference: 定义与示例亦见 [[Chemistry/4.Chemical_Bonds/bond_properties]] 的“4.3 氧化态与形式电荷”小节与 [[Chemistry/4.Chemical_Bonds/lewis_structures]]  
  See section “4.3 Oxidation State vs Formal Charge” in [[Chemistry/4.Chemical_Bonds/bond_properties]] and [[Chemistry/4.Chemical_Bonds/lewis_structures]]

## 氧化与还原 / Oxidation & Reduction

- 定义（电子转移视角）/ Definitions (electron-transfer view): 氧化=失电子（OS上升）；还原=得电子（OS下降）  
  Oxidation = loss of electrons (OS increases); Reduction = gain of electrons (OS decreases)
- 电子与流向 / Electron flow: 电子从还原剂流向氧化剂；电流方向与电子相反  
  Electrons flow from the reducing agent to the oxidizing agent; conventional current is opposite
- 判断方法 / Identification via OS: 比较反应前后某原子的氧化态；上升者被氧化，下降者被还原  
  Compare oxidation states before/after; increase means oxidized, decrease means reduced
- 经典示例 / Classic example: Zn(s)+Cu²⁺(aq)→Zn²⁺(aq)+Cu(s)；Zn: 0→+2（氧化，失2 e⁻），Cu: +2→0（还原，得2 e⁻）  
  Zn(s)+Cu²⁺(aq)→Zn²⁺(aq)+Cu(s); Zn: 0→+2 (oxidized, loses 2 e⁻), Cu: +2→0 (reduced, gains 2 e⁻)
- 燃烧与金属腐蚀 / Combustion & corrosion: 一般为氧化过程（被O₂或其他氧化剂夺电子）  
  Typically oxidation processes (electrons taken by O₂ or other oxidants)

## 氧化剂与还原剂 / Oxidizing vs Reducing Agents

- 定义 / Definitions: 氧化剂（oxidizing agent, oxidant）自身被还原；还原剂（reducing agent, reductant）自身被氧化  
  Oxidizing agent is reduced; Reducing agent is oxidized
- 判别技巧 / Quick cues: 含高OS元素/多氧的物种常为氧化剂；含低OS元素/富电子的物种常为还原剂  
  High-OS or oxygen-rich species tend to be oxidants; low-OS or electron-rich species tend to be reductants
- 常见氧化剂 / Common oxidants: O₂, H₂O₂（弱-中），卤素 X₂，过锰酸钾 KMnO₄（酸性强氧化），重铬酸盐 K₂Cr₂O₇（酸性），硝酸 HNO₃（浓强/稀温和），高氯酸盐 ClO₄⁻ 等  
  O₂, H₂O₂ (mild-moderate), halogens X₂, KMnO₄ (strong in acid), K₂Cr₂O₇ (acidic), HNO₃ (conc. strong/ dilute mild), perchlorates ClO₄⁻, etc.
- 常见还原剂 / Common reductants: 金属 M(0) 如 Zn、Fe、Al；金属氢化物 NaBH₄、LiAlH₄；硫代硫酸盐 S₂O₃²⁻；亚硫酸盐 SO₃²⁻；H₂、CO 等  
  Metals M(0) like Zn, Fe, Al; hydrides NaBH₄, LiAlH₄; thiosulfate S₂O₃²⁻; sulfite SO₃²⁻; H₂, CO, etc.
- 与电势关系 / Potentials: 更高的还原电势 E° 倾向作为氧化剂被还原；更低/更负的还原电势倾向作为还原剂被氧化  
  Higher standard reduction potential E° favors acting as oxidant; lower/more negative E° favors acting as reductant

## 半反应配平（酸/碱性条件）/ Half-Reaction Balancing (acidic/basic)

- 步骤（通用）/ General steps: 拆为两个半反应→除 O、H 外先配平原子→酸性条件加 H₂O 配 O、加 H⁺ 配 H；碱性条件在完成酸性配平后两侧同时加 OH⁻ 抵消 H⁺ 成 H₂O→以 e⁻ 配平电荷→倍乘使 e⁻ 数相等→相加并约去相同物种  
  Split into two half-reactions → balance all atoms except O, H → in acid add H₂O for O and H⁺ for H; in base, after acidic balancing add OH⁻ to both sides to neutralize H⁺ to H₂O → use e⁻ to balance charge → scale to equalize e⁻ → add and cancel common species
- 例（酸性，KMnO₄ 还原 Fe²⁺）/ Example (acidic, KMnO₄ reduces Fe²⁺):  
  MnO₄⁻→Mn²⁺（得5 e⁻）；Fe²⁺→Fe³⁺（失1 e⁻）；总反应含 5 个 Fe²⁺ 与 1 个 MnO₄⁻，并含 H⁺、H₂O 以配平  
  MnO₄⁻→Mn²⁺ (gains 5 e⁻); Fe²⁺→Fe³⁺ (loses 1 e⁻); overall uses 5 Fe²⁺ and 1 MnO₄⁻ with H⁺ and H₂O to balance
- 核对要点 / Checks: 原子守恒、总电荷守恒、电子数相消；在碱性条件应无游离 H⁺  
  Verify atom and net charge balance; electrons cancel; no free H⁺ in basic media

## 速记与判断 / Quick Notes

- “OIL RIG”/“LEO GER”: Oxidation Is Loss; Reduction Is Gain / Lose Electrons Oxidation; Gain Electrons Reduction  
  Helpful mnemonics for remembering electron flow and OS change
- OS 变化与剂判断 / OS change cues: 谁 OS 升高谁是还原剂（被氧化）；谁 OS 降低谁是氧化剂（被还原）  
  Species whose OS increases acted as reductant (was oxidized); OS decreases acted as oxidant (was reduced)

# Economics / 经济学

## 效用函数 / Utility Function

- 直觉 / Intuition：在不确定（有赌注）时，用“效用”而不是直接用钱数来比较方案。  Under risk, compare options by utility rather than raw dollars.
- 示例函数 / Example function：设$U(m)=\sqrt{m}$，其中$m$是钱数；该函数对钱的边际效用递减（曲线向下凹）。  Let $U(m)=\sqrt{m}$ for money $m$; it has diminishing marginal utility (concave curve).
- 期望效用 / Expected utility：$EU=\sum_i p_i\,U(m_i)$。  Compute expected utility as probability-weighted utility.

- 选项对比 / Options:
  - A：确定得到$80$ → $EU(A)=\sqrt{80}\approx8.94$。  A sure $\$80$ → $EU(A)=\sqrt{80}\approx8.94$.
  - B：50%得$150$、50%得$50$ → $EU(B)=\tfrac12\sqrt{150}+\tfrac12\sqrt{50}\approx9.66$（因此在此$U$下选B）。  50% $\$150$, 50% $\$50$ → $EU(B)\approx9.66$ (so choose B with this $U$).
  - C：20%得$250$、80%得$0$ → $EU(C)=0.2\sqrt{250}+0.8\sqrt{0}\approx3.16$。  20% $\$250$, 80% $\$0$ → $EU(C)\approx3.16$.

- 风险偏好 / Risk attitudes：
  - 风险厌恶：相同期望值下更喜欢确定金额；愿意少拿一点钱来避险；效用曲线凹。  Risk-averse: prefers a sure amount to an equal-EV gamble; concave $U$.
  - 风险中性：相同期望值下无差别；等价于“总是最大化EV”；效用线性。  Risk-neutral: indifferent at equal EV; effectively maximizes EV; linear $U$.
  - 风险寻求：相同期望值下更偏好赌局；愿意付出一些钱去冒险；效用凸。  Risk-seeking: prefers a gamble at equal EV; convex $U$.
  - 按选择判断 / Identify by choice：若选 A 则为风险厌恶；若选 C 则为风险寻求；风险中性者通常选 B（轻微厌恶/寻求者也可能选 B）。  By choices: choosing A implies risk-averse; choosing C implies risk-seeking; risk-neutral typically chooses B (slightly risk-averse/seeking may also choose B).

- 风险溢价 / Risk premium：把赌局换成一个“确定金额”时，你最多愿意放弃/愿意付出的钱。  The money you give up/pay to swap a gamble for a sure amount. 
  - 定义 / Definition：先求“确定等价物”$CE$ 使得 $U(CE)=EU$；再算 $RP=EV-CE$。  Find certainty equivalent $CE$ with $U(CE)=EU$, then $RP=EV-CE$.
  - 结论 / Result：风险厌恶 $RP>0$（愿意为避险让利）；风险中性 $RP=0$；风险寻求 $RP<0$（愿意倒贴去冒险）。  Risk-averse $RP>0$; risk-neutral $RP=0$; risk-seeking $RP<0$.

### 术语表 / Quick Glossary

| 符号/术语 / Term | 含义 / Meaning |
| :-- | :-- |
| $U(m)$ | 效用函数：把钱$m$映射到效用；形状刻画风险偏好（凹/线性/凸）。 Utility of money; shape shows risk attitude (concave/linear/convex). |
| $EU$ | 期望效用：$EU=\sum_i p_i\,U(m_i)$。 Expected utility: probability-weighted utility. |
| $EV$ | 期望值（钱）：$EV=\sum_i p_i\,m_i$。 Expected value in dollars. |
| $CE$ | 确定等价物：满足 $U(CE)=EU$ 的确定金额。 Certainty equivalent solves $U(CE)=EU$. |
| $RP$ | 风险溢价：$RP=EV-CE$；厌恶$>0$，中性$=0$，寻求$<0$。 Risk premium: $RP=EV-CE$; averse/neutral/seeking → $>0/=0/<0$. |
