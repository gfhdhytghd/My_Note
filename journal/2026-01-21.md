## 增广矩阵：无解与无数解 / Augmented Matrices: No Solution & Infinitely Many Solutions

给线性方程组写成增广矩阵$[A|\mathbf{b}]$，做行初等变换（化到$rref$或阶梯形）来判断解的情况。  
Write a linear system as an augmented matrix $[A|\mathbf{b}]$ and use row operations (to $rref$ or echelon form) to decide the solution type.

### 无解 / No Solution

当化简过程中出现“矛盾行”时无解：  
No solution occurs if a contradictory row appears after elimination:

$$
\left[\begin{array}{cccc|c}
0&0&\cdots&0&c
\end{array}\right],\quad c\neq0
$$

这代表$0=c$，因此方程组不相容（inconsistent），无解。  
This means $0=c$, so the system is inconsistent and has no solution.

### 无数解 / Infinitely Many Solutions

当系统相容且存在自由变量时有无穷多解：  
If the system is consistent and has free variables, it has infinitely many solutions:

- 判别（秩条件）/ Criterion (ranks): $\operatorname{rank}(A)=\operatorname{rank}([A|\mathbf{b}])<n$（$n$为未知数个数）。  
- 等价说法 / Equivalent view: 化到$rref$后主元列（pivot columns）少于未知数个数$\Rightarrow$至少一个自由变量$\Rightarrow$解集是一族参数解。  

一个直观例子：若$rref$里有一行是$[0\ 0\ 1\ |\ 2]$而某一列没有主元（比如$x_2$是自由变量），则可令$x_2=t$并写出其余变量关于$t$的表达式。  
Intuitively, if in $rref$ a variable has no pivot (e.g. $x_2$ is free), set $x_2=t$ and express the pivot variables in terms of $t$.
