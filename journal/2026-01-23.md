## Math Calculus / 数学 微积分

### $\int\sec^nx\tan^nx\,dx$ 的常用处理思路 / Common strategy for $\int\sec^nx\tan^nx\,dx$

- 恒等式 / Identities：$\tan^2x=\sec^2x-1$，$\sec^2x=1+\tan^2x$。
- $n$ 为奇数 / $n$ odd：拆出一个 $\sec x\tan x\,dx$，令 $u=\sec x$，$du=\sec x\tan x\,dx$；其余用 $\tan^2x=\sec^2x-1$ 化成 $u$ 的多项式：$\sec^{n-1}x\tan^{n-1}x=u^{n-1}(u^2-1)^{(n-1)/2}$。
  - 例 / Example（$n=3$）：$\int\sec^3x\tan^3x\,dx=\int u^2(u^2-1)\,du=\frac{u^5}{5}-\frac{u^3}{3}+C=\frac{\sec^5x}{5}-\frac{\sec^3x}{3}+C$。
- $n$ 为偶数且 $n\ge2$ / $n$ even and $n\ge2$：改写为 $\tan^nx\sec^{n-2}x\sec^2x\,dx$，令 $u=\tan x$，$du=\sec^2x\,dx$；其余用 $\sec^{n-2}x=(1+u^2)^{(n-2)/2}$。
  - 例 / Example（$n=2$）：$\int\sec^2x\tan^2x\,dx=\int u^2\,du=\frac{\tan^3x}{3}+C$。
- 特例 / Special case（$n=1$）：$\int\sec x\tan x\,dx=\sec x+C$。

## Physics 211 / 物理 211

### 向量的乘法 / Vector multiplication

- 标量乘法 / Scalar multiplication：$k\vec{a}$ 只改变长度（乘以 $|k|$）与方向（若 $k<0$ 则反向）/ $k\vec{a}$ scales magnitude by $|k|$ and flips direction if $k<0$.
- 点乘（内积）/ Dot product：$\vec{a}\cdot\vec{b}=|\vec{a}||\vec{b}|\cos\theta=a_xb_x+a_yb_y+a_zb_z$，结果是标量 / returns a scalar.
  - 几何意义 / Geometric meaning：$\vec{a}\cdot\vec{b}=|\vec{a}|\cdot(\text{b 在 a 方向的分量})$ / magnitude times the component of $\vec{b}$ along $\vec{a}$.
  - 物理例子 / Physics example：功 $W=\vec{F}\cdot\Delta\vec{r}$ / work.
- 叉乘（外积）/ Cross product：$\vec{a}\times\vec{b}=|\vec{a}||\vec{b}|\sin\theta\,\hat{n}$，方向由右手定则确定 / direction by right-hand rule.
  - 分量公式 / Component formula：$\vec{a}\times\vec{b}=(a_yb_z-a_zb_y,\;a_zb_x-a_xb_z,\;a_xb_y-a_yb_x)$ / in components.
  - 物理例子 / Physics examples：力矩 $\vec{\tau}=\vec{r}\times\vec{F}$，角动量 $\vec{L}=\vec{r}\times\vec{p}$ / torque, angular momentum.
- 混合积（三重积）/ Scalar triple product：$\vec{a}\cdot(\vec{b}\times\vec{c})$ 等于三向量张成平行六面体的有向体积 / signed volume; 也可写成行列式 / also a determinant.
