# Math Calculus

## 隐函数求导 / Implicit Differentiation

card![[Math_Calculus/3.Derivatives/implicit_differentiation]]

- 核心 / Core：把$y$当作$y(x)$，对等式两边对$x$求导（凡是出现$y$的地方都要乘上$y'=\dfrac{dy}{dx}$），最后解出$y'$。  
  Treat $y$ as $y(x)$, differentiate both sides w.r.t. $x$ (every time $y$ appears, a $y'=\dfrac{dy}{dx}$ comes out via chain rule), then solve for $y'$.

- 快速公式 / Quick formula：若$F(x,y)=0$且$F_y\neq0$，则$\dfrac{dy}{dx}=-\dfrac{F_x}{F_y}$。  
  If $F(x,y)=0$ and $F_y\neq0$, then $\dfrac{dy}{dx}=-\dfrac{F_x}{F_y}$.

### 小例子 / Quick example

- 对$x y+y^2=1$求导：$y+x y'+2y y'=0\Rightarrow(x+2y)y'=-y\Rightarrow y'=-\dfrac{y}{x+2y}$。  
  Differentiate $x y+y^2=1$: $y+x y'+2y y'=0\Rightarrow(x+2y)y'=-y\Rightarrow y'=-\dfrac{y}{x+2y}$.

## 相关变化率 / Related Rates

card![[Math_Calculus/3.Derivatives/related_rates]]

- 核心 / Core：把所有随时间变的量都看成$t$的函数，对约束方程两边对$t$求导，用已知的变化率（如$\dfrac{dx}{dt}$）去求未知变化率。  
  Treat every changing quantity as a function of time $t$. Differentiate the constraint equation w.r.t. $t$, then use known rates (e.g. $\dfrac{dx}{dt}$) to solve for the unknown rate.

- 常见坑 / Common pitfalls：先写清变量关系（画图/标注），再代入具体时刻数值；不要太早把变量当常数代入。  
  Write the relation first (diagram + labels), then plug in values at the given instant; don’t substitute numbers too early.

### 小例子 / Quick example（圆形膨胀 / Expanding circle）

- 圆面积$A=\pi r^2$，两边对$t$求导：$\dfrac{dA}{dt}=2\pi r\dfrac{dr}{dt}$。  
  With $A=\pi r^2$, differentiate: $\dfrac{dA}{dt}=2\pi r\dfrac{dr}{dt}$.
  - 若$r=3$且$\dfrac{dr}{dt}=0.2$，则$\dfrac{dA}{dt}=2\pi(3)(0.2)=1.2\pi$。  
    If $r=3$ and $\dfrac{dr}{dt}=0.2$, then $\dfrac{dA}{dt}=2\pi(3)(0.2)=1.2\pi$.
