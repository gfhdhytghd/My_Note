## Matrix Vector方程含有自由变量时的解集 / Solution Set with Free Variables in a Matrix-Vector Equation

设矩阵方程$A\mathbf{x}=\mathbf{b}$经过行化简后出现自由变量时，解集通常写成“特解 + 零空间方向”的参数形式。  
If free variables appear after row reduction of$A\mathbf{x}=\mathbf{b}$, the solution set is written in parametric form as “a particular solution + null-space directions”.

### 1. 无解 / No Solution

若化简后出现形如$[0\ 0\ \cdots\ 0\ |\ c]$且$c\neq0$，则方程不相容，解集为$\varnothing$。  
If a row like$[0\ 0\ \cdots\ 0\ |\ c]$with$c\neq0$appears, the system is inconsistent and the solution set is$\varnothing$.

### 2. 唯一解 / Unique Solution

若没有自由变量（每个未知量列都是主元列），则解唯一。  
If there are no free variables (every variable column is a pivot column), the solution is unique.

### 3. 无穷多解（有自由变量） / Infinitely Many Solutions (With Free Variables)

若有$k$个自由变量，就有$k$个参数$t_1,\dots,t_k$，解集可写为：  
If there are$k$free variables, introduce$k$parameters$t_1,\dots,t_k$, and write:

$$
\mathbf{x}=\mathbf{x}_p+t_1\mathbf{v}_1+\cdots+t_k\mathbf{v}_k,\quad t_i\in\mathbb{R}.
$$

其中$\mathbf{x}_p$是一个特解，$\mathbf{v}_1,\dots,\mathbf{v}_k$是齐次方程$A\mathbf{x}=\mathbf{0}$的基向量（零空间方向）。  
Here$\mathbf{x}_p$is a particular solution, and$\mathbf{v}_1,\dots,\mathbf{v}_k$are basis vectors of the homogeneous system$A\mathbf{x}=\mathbf{0}$(null-space directions).

### 4. 一个简例 / A Quick Example

化简后若得到  
Suppose RREF gives:

$$
\begin{cases}
x_1+2x_3=5\\
x_2-x_3=1
\end{cases}
$$

令自由变量$x_3=t$，则  
Let the free variable be$x_3=t$, then:

$$
x_1=5-2t,\quad x_2=1+t,\quad x_3=t.
$$

所以解集是  
So the solution set is:

$$
\left\{\begin{bmatrix}5-2t\\1+t\\t\end{bmatrix}:t\in\mathbb{R}\right\}
=\begin{bmatrix}5\\1\\0\end{bmatrix}
+t\begin{bmatrix}-2\\1\\1\end{bmatrix}.
$$

## Homogeneous定义 / Definition of Homogeneous

齐次线性系统（homogeneous linear system）是指常数项全为$0$的线性方程组。  
A homogeneous linear system is a linear system whose constant terms are all$0$.

A linear system is called homogeneous if it can be written as$A\mathbf{x}=\mathbf{0}$.  
如果一个线性系统可以写成$A\mathbf{x}=\mathbf{0}$，则称其为齐次系统。

## 解集的几何性质 / Geometric Properties of the Solution Set

在线性系统$A\mathbf{x}=\mathbf{b}$中，解集的几何形状由自由变量个数决定。  
For a linear system$A\mathbf{x}=\mathbf{b}$, the geometry of the solution set is determined by the number of free variables.

- 若无解：几何上表示这些约束超平面没有公共交点。  
- No solution: geometrically, the constraint hyperplanes have no common intersection.
- 若唯一解：解集是一个点（0维）。  
- Unique solution: the solution set is a single point (0D).
- 若有$k$个自由变量：解集是$k$维仿射子空间，可写成$\mathbf{x}_p+\mathcal{N}(A)$的一部分（方向由零空间给出）。  
- With$k$free variables: the solution set is a$k$-dimensional affine subspace, written as$\mathbf{x}_p+\mathcal{N}(A)$ (directions come from the null space).

对齐次系统$A\mathbf{x}=\mathbf{0}$，解集本身就是零空间$\mathcal{N}(A)$，一定经过原点。  
For a homogeneous system$A\mathbf{x}=\mathbf{0}$, the solution set is exactly the null space$\mathcal{N}(A)$ and always passes through the origin.

对非齐次系统$A\mathbf{x}=\mathbf{b}$（若相容），解集是零空间的平移，一般不经过原点。  
For a non-homogeneous system$A\mathbf{x}=\mathbf{b}$ (if consistent), the solution set is a translation of the null space and generally does not pass through the origin.

## 矩阵方程的两个核心问题 / Two Core Questions of Matrix Equations

这页可以看作在总结矩阵方程的两个核心问题：左栏问“哪些输出可能出现”，右栏问“哪些输入会产生指定输出”。  
This page can be viewed as a summary of two core questions: the left asks “which outputs are possible,” and the right asks “which inputs produce a specified output.”

### 左栏：给定$A$，哪些$\mathbf{b}$可能出现？ / Left: Given$A$, which$\mathbf{b}$are attainable?

核心想法：$\mathbf{b}$必须是$A$的列向量线性组合，即$\mathbf{b}\in\mathrm{Col}(A)$。  
Core idea: $\mathbf{b}$must be a linear combination of columns of$A$, i.e.$\mathbf{b}\in\mathrm{Col}(A)$.

结论：所有可能输出正好是$A$的列空间，也就是“$A$的列向量张成空间”。  
Conclusion: all attainable outputs are exactly the column space of$A$, i.e. the span of columns of$A$.

维数关系：$\dim(\mathrm{Col}(A))=\mathrm{rank}(A)=$主元个数。  
Dimension relation: $\dim(\mathrm{Col}(A))=\mathrm{rank}(A)=$number of pivots.

补充：$\mathbf{0}$一定在任何span里（所有系数取$0$）。  
Note: $\mathbf{0}$is always in any span (all coefficients set to$0$).

### 右栏：给定$A$和$\mathbf{b}$，哪些$\mathbf{x}$会得到这个$\mathbf{b}$？ / Right: Given$A$and$\mathbf{b}$, which$\mathbf{x}$solve it?

做法：解方程$A\mathbf{x}=\mathbf{b}$。  
Method: solve$A\mathbf{x}=\mathbf{b}$.

若相容，解集通常是点/直线/平面/更高维仿射子空间；其维数等于自由变量个数。  
If consistent, the solution set is typically a point/line/plane/higher-dimensional affine subspace; its dimension equals the number of free variables.

重要区别：$A\mathbf{x}=\mathbf{0}$一定是齐次系统；非齐次系统$A\mathbf{x}=\mathbf{b}$中，$\mathbf{0}$一般不是解（除非$\mathbf{b}=\mathbf{0}$）。  
Key distinction: $A\mathbf{x}=\mathbf{0}$is always homogeneous; for non-homogeneous$A\mathbf{x}=\mathbf{b}$,$\mathbf{0}$is generally not a solution (unless$\mathbf{b}=\mathbf{0}$).

### 一句话总总结 / One-Line Exam Summary

左问：哪些$\mathbf{b}$能出现？看列空间$\mathrm{Col}(A)$。  
Left question: which$\mathbf{b}$can appear? Check the column space$\mathrm{Col}(A)$.

右问：哪些$\mathbf{x}$能解出来？看自由变量与解集参数化。  
Right question: which$\mathbf{x}$solve it? Check free variables and parametrization.

主元数$=\mathrm{rank}(A)=\dim(\mathrm{Col}(A))$；自由变量数$=n-\mathrm{rank}(A)=\dim(\mathcal{N}(A))$。  
Number of pivots$=\mathrm{rank}(A)=\dim(\mathrm{Col}(A))$; number of free variables$=n-\mathrm{rank}(A)=\dim(\mathcal{N}(A))$.
