## 有理函数积分与分部分式 / Integration of Rational Functions and Partial Fractions

黑板主式是$\int\frac{P(x)}{Q(x)}\,dx$，其中“polynomial in$x$/polynomial in$x$”表示分子分母都是多项式。  
The board starts from$\int\frac{P(x)}{Q(x)}\,dx$, where “polynomial in$x$/polynomial in$x$” means both numerator and denominator are polynomials.

老师标注“Assume$\deg P<\deg Q$”是在说先处理真分式；若$\deg P\ge\deg Q$，要先长除把它改成“多项式+真分式”。  
“Assume$\deg P<\deg Q$” means we first handle proper rational functions; if$\deg P\ge\deg Q$, do long division first to rewrite as “polynomial + proper fraction.”

### 通用步骤 / Standard Workflow

1. 若不是真分式，先长除。  
1. If not proper, do polynomial long division first.
2. 分解$Q(x)$为线性与不可约二次因子。  
2. Factor$Q(x)$ into linear and irreducible quadratic factors.
3. 按 Case I-IV 写部分分式模板。  
3. Write the partial-fraction template according to Case I-IV.
4. 解未知系数（代入法或比较系数）。  
4. Solve unknown coefficients (plug-in values or coefficient matching).
5. 逐项积分并合并常数$C$。  
5. Integrate term-by-term and combine constants into$C$.

## Case I：不重复一次因子 / Distinct Linear Factors

分母是不同线性因子乘积时，用常数分子：$\frac{A}{x-a}+\frac{B}{x-b}+\cdots$。  
For distinct linear factors in the denominator, use constant numerators: $\frac{A}{x-a}+\frac{B}{x-b}+\cdots$.

### 范例 / Example

$$
\int\frac{x+5}{(x+1)(x+2)}\,dx.
$$

设  
Set

$$
\frac{x+5}{(x+1)(x+2)}=\frac{A}{x+1}+\frac{B}{x+2}.
$$

则$x+5=A(x+2)+B(x+1)$，代$x=-1,-2$得$A=4,B=-3$。  
Then$x+5=A(x+2)+B(x+1)$; plugging$x=-1,-2$ gives$A=4,B=-3$.

$$
\int\frac{x+5}{(x+1)(x+2)}\,dx
=\int\left(\frac{4}{x+1}-\frac{3}{x+2}\right)\,dx
=4\ln|x+1|-3\ln|x+2|+C.
$$

## Case II：重复一次因子 / Repeated Linear Factors

若有$(x-a)^n$，必须从$1$次写到$n$次：$\frac{A_1}{x-a}+\frac{A_2}{(x-a)^2}+\cdots+\frac{A_n}{(x-a)^n}$。  
If$(x-a)^n$ appears, include every power from$1$to$n$: $\frac{A_1}{x-a}+\frac{A_2}{(x-a)^2}+\cdots+\frac{A_n}{(x-a)^n}$.

### 范例 / Example

$$
\int\frac{1}{x(x+1)^2}\,dx.
$$

设  
Set

$$
\frac{1}{x(x+1)^2}=\frac{A}{x}+\frac{B}{x+1}+\frac{C}{(x+1)^2}.
$$

通分后得$1=A(x+1)^2+Bx(x+1)+Cx$，解得$A=1,B=-1,C=-1$。  
After clearing denominators:$1=A(x+1)^2+Bx(x+1)+Cx$, giving$A=1,B=-1,C=-1$.

$$
\int\frac{1}{x(x+1)^2}\,dx
=\int\left(\frac{1}{x}-\frac{1}{x+1}-\frac{1}{(x+1)^2}\right)\,dx
=\ln|x|-\ln|x+1|+\frac{1}{x+1}+C.
$$

## Case III：不重复不可约二次因子 / Distinct Irreducible Quadratics

每个不可约二次因子$(x^2+bx+c)$对应一次分子$(Ax+B)$。  
Each irreducible quadratic factor$(x^2+bx+c)$ must pair with a linear numerator$(Ax+B)$.

### 范例 / Example

$$
\int\frac{3x+5}{(x^2+1)(x^2+4)}\,dx.
$$

设  
Set

$$
\frac{3x+5}{(x^2+1)(x^2+4)}=\frac{Ax+B}{x^2+1}+\frac{Cx+D}{x^2+4}.
$$

解得$A=1,B=\frac{5}{3},C=-1,D=-\frac{5}{3}$。  
Solving gives$A=1,B=\frac{5}{3},C=-1,D=-\frac{5}{3}$.

因此  
Hence

$$
\int\frac{3x+5}{(x^2+1)(x^2+4)}\,dx
=\frac{1}{2}\ln(x^2+1)-\frac{1}{2}\ln(x^2+4)
+\frac{5}{3}\arctan x-\frac{5}{6}\arctan\left(\frac{x}{2}\right)+C.
$$

这里就出现了$\ln$型与$\arctan$型。  
This directly produces both$\ln$-type and$\arctan$-type antiderivatives.

## Case IV：重复不可约二次因子 / Repeated Irreducible Quadratics

若有$(x^2+bx+c)^n$，要写成  
If$(x^2+bx+c)^n$ appears, write

$$
\frac{A_1x+B_1}{x^2+bx+c}
+\frac{A_2x+B_2}{(x^2+bx+c)^2}
+\cdots
+\frac{A_nx+B_n}{(x^2+bx+c)^n}.
$$

### 范例 / Example

$$
\int\frac{1}{(x^2+1)^2}\,dx.
$$

这是 Case IV 的基础型，积分结果常背作  
This is a core Case IV prototype; a standard antiderivative is

$$
\int\frac{1}{(x^2+1)^2}\,dx
=\frac{x}{2(x^2+1)}+\frac{1}{2}\arctan x+C.
$$

该结果可看成“有理项+反三角项”的组合。  
This result is a combination of a rational term and an inverse-trig term.

## 为什么最后常见$\ln/\arctan/\text{幂函数}$ / Why$\ln/\arctan/\text{power}$Appear

- $\int\frac{1}{x-a}\,dx=\ln|x-a|+C$。  
- $\int\frac{1}{x-a}\,dx=\ln|x-a|+C$.
- $\int\frac{1}{x^2+a^2}\,dx=\frac{1}{a}\arctan\left(\frac{x}{a}\right)+C$。  
- $\int\frac{1}{x^2+a^2}\,dx=\frac{1}{a}\arctan\left(\frac{x}{a}\right)+C$.
- $\int(x-a)^{-n}\,dx$（$n\neq1$）给幂函数形式。  
- $\int(x-a)^{-n}\,dx$($n\neq1$) gives power-function forms.

所以部分分式分解的本质，就是把复杂有理函数拆到这些“可直接积分的标准块”。  
So the essence of partial fractions is decomposing a complicated rational function into these standard integrable blocks.

### 一句话总结 / One-Line Summary

把$\frac{P(x)}{Q(x)}$按因子类型拆成简单分式，再逐项积分。  
Decompose$\frac{P(x)}{Q(x)}$by factor type into simple fractions, then integrate term by term.

## 线性代数定义：Transformation / Definitions for Transformations

### Def 1: Transformation（变换）

变换是一个函数，其输入和输出都是向量。  
A transformation is a function where both inputs and outputs are vectors.

常记作$T:\mathbb{R}^n\to\mathbb{R}^m$。  
It is commonly written as$T:\mathbb{R}^n\to\mathbb{R}^m$.

### Domain（定义域）

定义域是输入向量所在的欧几里得空间。  
The domain is the Euclidean space where input vectors live.

例如在$T:\mathbb{R}^n\to\mathbb{R}^m$里，定义域是$\mathbb{R}^n$。  
For$T:\mathbb{R}^n\to\mathbb{R}^m$, the domain is$\mathbb{R}^n$.

### Codomain（陪域）

陪域是“声明的”输出空间，即输出应落入的目标欧几里得空间。  
The codomain is the declared output space, i.e. the target Euclidean space for outputs.

在$T:\mathbb{R}^n\to\mathbb{R}^m$里，陪域是$\mathbb{R}^m$。  
In$T:\mathbb{R}^n\to\mathbb{R}^m$, the codomain is$\mathbb{R}^m$.

### Image of a Vector（某个向量的像）

某个具体向量$\mathbf{v}$的像，就是它经过变换后的输出。  
The image of a specific vector$\mathbf{v}$ is its output under the transformation.

$$
\text{image of }\mathbf{v}=T(\mathbf{v}).
$$

### Range（值域）

值域是所有可能输出向量组成的集合。  
The range is the set of all possible output vectors.

$$
\text{Range}(T)=\{T(\mathbf{x})\mid\mathbf{x}\in\text{Domain}(T)\}.
$$

### 考试高频：Codomain vs Range / Exam Focus: Codomain vs Range

- `Codomain`是题目先给定的“目标空间”；`Range`是实际能打到的输出集合。  
- `Codomain` is the declared target space; `Range` is the set actually reached.
- 永远有$\text{Range}(T)\subseteq\text{Codomain}(T)$，但不一定相等。  
- Always$\text{Range}(T)\subseteq\text{Codomain}(T)$, but not necessarily equal.
- 若题目问“onto / surjective”，本质是在判断$\text{Range}(T)=\text{Codomain}(T)$是否成立。  
- If asked whether$T$is onto/surjective, check whether$\text{Range}(T)=\text{Codomain}(T)$.

## 线性变换速记 / Linear Transformation Cheat Sheet

### 定义 / Definition

若$T:V\to W$满足对任意向量$\mathbf{u},\mathbf{v}$与标量$c$：  
If$T:V\to W$satisfies, for all vectors$\mathbf{u},\mathbf{v}$and scalar$c$:

$$
T(\mathbf{u}+\mathbf{v})=T(\mathbf{u})+T(\mathbf{v}),\quad
T(c\mathbf{u})=cT(\mathbf{u}),
$$

则$T$是线性变换。  
then$T$is a linear transformation.

### 快速判定 / Quick Tests

- 先看$T(\mathbf{0})$是否等于$\mathbf{0}$；若不等于，立刻不是线性。  
- Check whether$T(\mathbf{0})=\mathbf{0}$first; if not, it is not linear.
- 含有常数平移项（如$+3,+\mathbf{b}$）通常不是线性，而是仿射变换。  
- A constant shift term (e.g.$+3,+\mathbf{b}$) usually means non-linear (affine instead).
- 含乘积、绝对值、平方等结构时，通常要用加法/齐次性直接反例检验。  
- Product, absolute value, or square terms usually fail linearity; verify by counterexample.

### 矩阵表示 / Matrix Representation

对有限维空间，任一线性变换都可写成  
In finite-dimensional spaces, every linear transformation can be written as

$$
T(\mathbf{x})=A\mathbf{x}.
$$

矩阵$A$的第$j$列就是$T(\mathbf{e}_j)$（标准基向量的像）。  
The$j$-th column of$A$is$T(\mathbf{e}_j)$, the image of the$j$-th standard basis vector.

### Kernel 与 Image / Kernel and Image

- $\ker(T)=\{\mathbf{x}\in V:T(\mathbf{x})=\mathbf{0}\}$，表示被压到零向量的输入集合。  
- $\ker(T)=\{\mathbf{x}\in V:T(\mathbf{x})=\mathbf{0}\}$, the set of inputs mapped to zero.
- $\mathrm{Im}(T)=\{T(\mathbf{x}):\mathbf{x}\in V\}$，就是$T$的值域（range）。  
- $\mathrm{Im}(T)=\{T(\mathbf{x}):\mathbf{x}\in V\}$, which is the range of$T$.

对$T(\mathbf{x})=A\mathbf{x}$，有$\ker(T)=\mathcal{N}(A)$，$\mathrm{Im}(T)=\mathrm{Col}(A)$。  
For$T(\mathbf{x})=A\mathbf{x}$, we have$\ker(T)=\mathcal{N}(A)$and$\mathrm{Im}(T)=\mathrm{Col}(A)$.

### One-to-One 与 Onto / One-to-One and Onto

- `one-to-one`$\Leftrightarrow\ker(T)=\{\mathbf{0}\}$（仅零解）。  
- `one-to-one`$\Leftrightarrow\ker(T)=\{\mathbf{0}\}$ (only trivial kernel).
- `onto`$\Leftrightarrow\mathrm{Im}(T)=W$（值域等于陪域）。  
- `onto`$\Leftrightarrow\mathrm{Im}(T)=W$ (range equals codomain).

若$T:\mathbb{R}^n\to\mathbb{R}^m$对应矩阵$A_{m\times n}$：  
If$T:\mathbb{R}^n\to\mathbb{R}^m$corresponds to$A_{m\times n}$:

- one-to-one$\Leftrightarrow\mathrm{rank}(A)=n$（每列有主元）。  
- one-to-one$\Leftrightarrow\mathrm{rank}(A)=n$ (pivot in every column).
- onto$\Leftrightarrow\mathrm{rank}(A)=m$（每行有主元）。  
- onto$\Leftrightarrow\mathrm{rank}(A)=m$ (pivot in every row).

### 小例子 / Quick Example

设$T:\mathbb{R}^2\to\mathbb{R}^2$，$T(x,y)=(x+2y,3x+6y)$。  
Let$T:\mathbb{R}^2\to\mathbb{R}^2$with$T(x,y)=(x+2y,3x+6y)$.

对应矩阵  
Its matrix is

$$
A=\begin{bmatrix}1&2\\3&6\end{bmatrix}.
$$

第二行是第一行的$3$倍，所以$\mathrm{rank}(A)=1$。  
Row 2 is$3$times row 1, so$\mathrm{rank}(A)=1$.

因此它既不是 one-to-one（核非平凡），也不是 onto（值域只是一条直线）。  
So it is neither one-to-one (nontrivial kernel) nor onto (range is only a line).
