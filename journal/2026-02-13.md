A trasformation is onto if the range is the entire codomain
如果一个变换的值域等于整个陪域，那么它是满射（onto）。

A transformation is one-to-one if no two inputs have the same output.
如果一个变换是单射（one-to-one），则不会有两个不同输入对应同一个输出。

A loasis(of R^n) is a set of linearly independent vector that span in R^n
$\mathbb{R}^n$ 的一组基（basis）是：一组既线性无关、又能张成 $\mathbb{R}^n$ 的向量。

Examples / 例子：

- Onto example / 满射示例：$f:\mathbb{R}\to\mathbb{R}$, $f(x)=x^3$ is onto because every real number has some cube root preimage.  
  $f:\mathbb{R}\to\mathbb{R}$ 的函数 $f(x)=x^3$ 是满射，因为任意实数 $y$ 都有 $x=\sqrt[3]{y}$ 使得 $f(x)=y$。
- Not onto example / 非满射示例：$g:\mathbb{R}\to\mathbb{R}$, $g(x)=x^2$ is not onto since no real $x$ maps to $-1$.  
  $g:\mathbb{R}\to\mathbb{R}$, $g(x)=x^2$ 不是满射，因为不存在实数 $x$ 使得 $x^2=-1$。
- One-to-one example / 单射示例：$h:\mathbb{R}\to\mathbb{R}$, $h(x)=2x+1$ is one-to-one because if $h(a)=h(b)$ then $a=b$.  
  $h:\mathbb{R}\to\mathbb{R}$, $h(x)=2x+1$ 是单射，因为 $h(a)=h(b)\Rightarrow a=b$。
- Not one-to-one example / 非单射示例：$k:\mathbb{R}\to\mathbb{R}$, $k(x)=x^2$ is not one-to-one since $k(1)=k(-1)=1$ but $1\neq -1$.  
  $k:\mathbb{R}\to\mathbb{R}$, $k(x)=x^2$ 不是单射，因为 $k(1)=k(-1)=1$ 但 $1\neq -1$。
- Basis example / 基向量组示例：在 $\mathbb{R}^2$ 中，$\{(1,0),(0,1)\}$ 是一组基。  
  In $\mathbb{R}^2$, $\{(1,0),(0,1)\}$ is a basis because they are independent and any vector $(a,b)$ can be written as $a(1,0)+b(0,1)$.  
  在 $\mathbb{R}^2$ 中，任意向量 $(a,b)$ 都可写成 $a(1,0)+b(0,1)$
标准矩阵与变换组合 / Standard Matrix and Composition

若线性变换 $T:\mathbb{R}^n\to\mathbb{R}^m$ 的标准矩阵为 $A$，
则

$$
A=[T(\mathbf e_1)\;T(\mathbf e_2)\;\dots\;T(\mathbf e_n)].
$$

若 $S:\mathbb{R}^m\to\mathbb{R}^p$ 的标准矩阵为 $B$，则

$$
(S\circ T)(\mathbf x)=S(T(\mathbf x))=B(A\mathbf x)=(BA)\mathbf x.
$$

因此，$S\circ T$ 的标准矩阵是

$$
BA.
$$

口诀 / Key rule

- 先做 $T$，再做 $S$，矩阵写作 $BA$。  
  Do $T$ first, then $S$: matrix order is $BA$.
- 维度匹配：若 $A$ 是 $m\times n$，$B$ 是 $p\times m$，则 $BA$ 是 $p\times n$。  
  Dimension check: if $A$ is $m\times n$ and $B$ is $p\times m$, then $BA$ is $p\times n$.
- 一般不交换：$AB\neq BA$。  
  In general, matrix multiplication is non-commutative: $AB\neq BA$.

例子 / Example：

设

$$
A=\begin{bmatrix}0&-1\\1&0\end{bmatrix}\quad(\text{旋转 }90^\circ),
\quad
B=\begin{bmatrix}2&0\\0&1\end{bmatrix}\quad(\text{拉伸 }x\text{方向}).
$$

先旋转后拉伸是 $BA$，
先拉伸后旋转是 $AB$，两者不相等。  
This is why order matters in composition.
