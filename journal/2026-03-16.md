# Math 140

## Sequences / 数列
数列（sequence）可以看成定义在正整数上的函数：$a_1,a_2,a_3,\dots$。  
A sequence can be viewed as a function whose domain is the positive integers: $a_1,a_2,a_3,\dots$.

### Convergence / 收敛性
若存在实数 $L$，使得当 $n\to\infty$ 时 $a_n\to L$，则称数列 $\{a_n\}$ 收敛到 $L$。  
If there exists a real number $L$ such that $a_n\to L$ as $n\to\infty$, then the sequence $\{a_n\}$ converges to $L$.

若极限不存在，或数列无界增长/振荡不停，则称其发散。  
If the limit does not exist, or the sequence grows without bound or keeps oscillating, then it diverges.

### Monotonicity / 单调性
- 单调递增：若 $a_{n+1}\ge a_n$ 对所有充分大的 $n$ 都成立。  
  Monotonically increasing: if $a_{n+1}\ge a_n$ for all sufficiently large $n$.
- 单调递减：若 $a_{n+1}\le a_n$ 对所有充分大的 $n$ 都成立。  
  Monotonically decreasing: if $a_{n+1}\le a_n$ for all sufficiently large $n$.

单调性本身不保证收敛；还需要结合有界性一起判断。  
Monotonicity alone does not guarantee convergence; it must be combined with boundedness.

### Bounded Above / Below / 上下有界
- 有上界：存在常数 $M$，使得对所有 $n$ 都有 $a_n\le M$。  
  Bounded above: there exists a constant $M$ such that $a_n\le M$ for all $n$.
- 有下界：存在常数 $m$，使得对所有 $n$ 都有 $a_n\ge m$。  
  Bounded below: there exists a constant $m$ such that $a_n\ge m$ for all $n$.
- 有界：同时有上界和下界。  
  Bounded: bounded both above and below.

### Monotone Convergence Theorem / 单调收敛定理
若数列单调递增且有上界，则它收敛；若数列单调递减且有下界，则它也收敛。  
If a sequence is monotonically increasing and bounded above, then it converges; if it is monotonically decreasing and bounded below, it also converges.

更精确地说，单调递增有上界的数列收敛到其上确界，单调递减有下界的数列收敛到其下确界。  
More precisely, an increasing sequence bounded above converges to its supremum, and a decreasing sequence bounded below converges to its infimum.

### Alternating Sequences / 交错数列
交错数列（alternating sequence）通常指符号正负交替，例如 $a_n=(-1)^n$ 或 $a_n=(-1)^{n+1}b_n$。  
An alternating sequence usually means the signs alternate, for example $a_n=(-1)^n$ or $a_n=(-1)^{n+1}b_n$.

$(-1)^n$ 本身不收敛，因为它在 $1$ 和 $-1$ 之间来回跳动。  
$(-1)^n$ itself does not converge because it keeps jumping between $1$ and $-1$.

若交错数列的“振幅”趋于 $0$，则常常会收敛到 $0$；典型例子是 $\dfrac{(-1)^n}{n}\to0$。  
If the “amplitude” of an alternating sequence goes to $0$, then it often converges to $0$; a typical example is $\dfrac{(-1)^n}{n}\to0$.

### Squeeze Theorem / 夹逼定理
若对所有充分大的 $n$，都有 $u_n\le a_n\le v_n$，且 $\lim_{n\to\infty}u_n=\lim_{n\to\infty}v_n=L$，则 $\lim_{n\to\infty}a_n=L$。  
If for all sufficiently large $n$ we have $u_n\le a_n\le v_n$, and $\lim_{n\to\infty}u_n=\lim_{n\to\infty}v_n=L$, then $\lim_{n\to\infty}a_n=L$.

例子：因为
As an example, since
$$
-\frac{1}{n}\le\frac{(-1)^n}{n}\le\frac{1}{n}
$$
且左右两边都趋于 $0$，所以 $\dfrac{(-1)^n}{n}\to0$。  
and both outer sequences approach $0$, we get $\dfrac{(-1)^n}{n}\to0$.

对函数极限也是同样思路；经典三角函数例子可见 [[Math_Calculus/2.Limit/squeeze_theorem_trigonometric]]。  
The same idea works for function limits; a classic trigonometric example is in [[Math_Calculus/2.Limit/squeeze_theorem_trigonometric]].

### Quick Checklist / 做题检查点
- 先看数列是否单调。  
  First check whether the sequence is monotone.
- 再看是否有上界或下界。  
  Then check whether it is bounded above or below.
- 遇到交错项时，先看绝对值是否趋于 $0$。  
  For alternating terms, first check whether the absolute value goes to $0$.
- 遇到振荡但幅度变小的表达式，优先考虑夹逼。  
  For oscillatory expressions with shrinking amplitude, consider the squeeze theorem first.

## Vector Spaces / 向量空间
今天课堂上先抓“向量空间”的核心直觉：一个集合若包含零向量，并且对加法和数乘都封闭，就很可能是向量空间。  
In class, we first focused on the core intuition of a vector space: if a set contains the zero vector and is closed under addition and scalar multiplication, then it is a strong candidate for being a vector space.

严格定义还包括交换律、结合律、分配律等公理；课堂笔记里先记住“零向量 + 两种封闭性”这个检查框架。  
The full definition also includes commutativity, associativity, distributive laws, and other axioms; for lecture notes, the quick framework to remember is “zero vector + two closure properties.”

- 若 $X,Y\in S$，则 $X+Y\in S$。  
  If $X,Y\in S$, then $X+Y\in S$.
- 若 $X\in S$ 且 $k\in\mathbb{R}$，则 $kX\in S$。  
  If $X\in S$ and $k\in\mathbb{R}$, then $kX\in S$.
- 记号 $\in$ 表示“是集合中的元素”。  
  The symbol $\in$ means “is an element of.”

例：  
Example:
$$
k\begin{bmatrix}a\\b\\c\end{bmatrix}
=
\begin{bmatrix}ka\\kb\\kc\end{bmatrix}
$$

## Matrix Spaces / 矩阵空间
$M_{a\times b}(\mathbb{R})$ 表示所有元素都在 $\mathbb{R}$ 中的 $a\times b$ 矩阵的集合。  
$M_{a\times b}(\mathbb{R})$ denotes the set of all $a\times b$ matrices with entries in $\mathbb{R}$.

例如：
For example:
$$
M_{2\times2}(\mathbb{R})
=
\left\{
\begin{bmatrix}
a&b\\
c&d
\end{bmatrix}
\,\middle|\,
a,b,c,d\in\mathbb{R}
\right\}
$$

$M_{2\times2}(\mathbb{R})$ 非空，因为零矩阵属于其中。  
$M_{2\times2}(\mathbb{R})$ is non-empty because the zero matrix belongs to it.

两个 $2\times2$ 矩阵相加仍是 $2\times2$ 矩阵；一个 $2\times2$ 矩阵乘以标量后也仍是 $2\times2$ 矩阵。  
Adding two $2\times2$ matrices still gives a $2\times2$ matrix; multiplying a $2\times2$ matrix by a scalar also stays in the same set.

所以矩阵空间对加法和数乘封闭。  
So matrix spaces are closed under addition and scalar multiplication.

## Polynomial Spaces / 多项式空间
$P_n(\mathbb{R})$ 表示所有次数不超过 $n$、且系数属于 $\mathbb{R}$ 的多项式。  
$P_n(\mathbb{R})$ denotes all polynomials of degree at most $n$ with coefficients in $\mathbb{R}$.

零多项式属于 $P_n(\mathbb{R})$，所以这个集合非空。  
The zero polynomial belongs to $P_n(\mathbb{R})$, so the set is non-empty.

若 $f_1,f_2\in P_n(\mathbb{R})$，则 $f_1+f_2$ 的次数仍不超过 $n$；若 $f\in P_n(\mathbb{R})$，则 $kf$ 也仍在这个集合里。  
If $f_1,f_2\in P_n(\mathbb{R})$, then $f_1+f_2$ still has degree at most $n$; if $f\in P_n(\mathbb{R})$, then $kf$ also stays in the set.

例：
Example:
$$
P_2(\mathbb{R})=\{ax^2+bx+c\mid a,b,c\in\mathbb{R}\}
$$
