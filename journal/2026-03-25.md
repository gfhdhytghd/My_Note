### **无穷级数收敛判别：四个常用方法 + 一个积分 / Convergence Tests for Infinite Series**

*   **核心问题**：判断无穷级数$\sum a_n$是否收敛；**Core question**: determine whether the infinite series $\sum a_n$ converges.

#### **一、四个基础判别 / Four Basic Tests**

##### **1. 发散判别法 / Divergence Test**

*   **先检查项是否趋近于$0$**：如果$\lim_{n\to\infty}a_n\neq0$，则$\sum a_n$一定发散；**First check whether the terms approach zero**: if $\lim_{n\to\infty}a_n\neq0$, then $\sum a_n$ must diverge.
*   **注意**：如果$\lim_{n\to\infty}a_n=0$，只能说明级数“有可能”收敛，不能直接下结论；**Note**: if $\lim_{n\to\infty}a_n=0$, the series only has a chance to converge, but this is not sufficient.

##### **2. 比较判别法 / Comparison Test**

*   **核心思想**：把$a_n$和一个已知收敛性的级数$b_n$比较；**Core idea**: compare $a_n$ with a benchmark series $b_n$ whose behavior is known.
*   **常见基准**：$\sum\frac{1}{n^p}$在$p>1$时收敛，在$p\leq1$时发散；**Common benchmark**: the $p$-series $\sum\frac{1}{n^p}$ converges for $p>1$ and diverges for $p\leq1$.
*   **收敛比较**：若$0\leq a_n\leq b_n$且$\sum b_n$收敛，则$\sum a_n$也收敛；**Convergence comparison**: if $0\leq a_n\leq b_n$ and $\sum b_n$ converges, then $\sum a_n$ also converges.
*   **发散比较**：若$0\leq a_n\leq b_n$且$\sum a_n$发散，则$\sum b_n$也发散；**Divergence comparison**: if $0\leq a_n\leq b_n$ and $\sum a_n$ diverges, then $\sum b_n$ must also diverge.

##### **3. 极限比较判别法 / Limit Comparison Test**

*   **考试中更常用**：如果
    $$
    \lim_{n\to\infty}\frac{a_n}{b_n}=c,\quad0<c<\infty
    $$
    那么$\sum a_n$和$\sum b_n$同收敛或同发散；**More practical in exams**: if the limit above exists with $0<c<\infty$, then $\sum a_n$ and $\sum b_n$ have the same convergence behavior.

##### **4. 比值判别法 / Ratio Test**

*   **适合对象**：当$a_n$里出现$n!$、$c^n$、或高次幂连乘结构时，优先考虑比值判别；**Best use case**: when $a_n$ contains factorials, powers like $c^n$, or product-like growth, the ratio test is often the fastest choice.
*   **计算核心极限**：
    $$
    L=\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|
    $$
    若该极限存在，则可直接判断；**Compute the key limit**: if the limit above exists, it gives a direct conclusion.
*   **判别结论**：若$L<1$，则$\sum a_n$绝对收敛；若$L>1$或$L=\infty$，则$\sum a_n$发散；若$L=1$，则此判别法无效，不代表条件收敛；**Conclusion**: if $L<1$, then $\sum a_n$ converges absolutely; if $L>1$ or $L=\infty$, then $\sum a_n$ diverges; if $L=1$, the test is inconclusive and does not mean conditional convergence.

#### **二、一个积分判别 / The Integral Test**

*   **适用条件**：令$a_n=f(n)$，其中$f(x)$在$x\geq1$上是正的、连续的、单调递减的；**Conditions**: let $a_n=f(n)$, where $f(x)$ is positive, continuous, and decreasing for $x\geq1$.
*   **判别结论**：
    $$
    \sum a_n\quad\text{和}\quad\int_1^\infty f(x)\,dx
    $$
    同收敛或同发散；**Conclusion**: the series and the improper integral either both converge or both diverge.
*   **经典例子**：
    $$
    \int_1^\infty\frac{1}{x^p}\,dx
    $$
    在$p>1$时收敛，在$p\leq1$时发散，所以$\sum\frac{1}{n^p}$也有同样结论；**Classic example**: the integral above converges for $p>1$ and diverges for $p\leq1$, so $\sum\frac{1}{n^p}$ has the same result.

#### **三、实战判断流程 / Quick Workflow**

1.  **先算$\lim_{n\to\infty}a_n$**：若极限不为$0$，直接判发散；**First compute $\lim_{n\to\infty}a_n$**: if the limit is not $0$, the series diverges immediately.
2.  **再看级数形状**：若像$\frac{1}{n^p}$、$\frac{1}{n\ln n}$或有理函数，优先考虑比较判别或极限比较；**Then inspect the form**: for expressions like $\frac{1}{n^p}$, $\frac{1}{n\ln n}$, or rational functions, comparison tests are usually best.
3.  **若出现$n!$、$c^n$或相邻项相除能明显化简**：优先尝试比值判别；**If factorials, exponential terms, or simple cancellation in $\frac{a_{n+1}}{a_n}$ appear**: try the ratio test first.
4.  **若能自然写成函数$f(x)$**：并且满足正、连续、递减，就考虑积分判别；**If the terms naturally come from a function $f(x)$**: and it is positive, continuous, and decreasing, use the integral test.

#### **四、最关键的提醒 / Key Warning**

*   **项趋于$0$只是必要条件，不是充分条件**：例如调和级数$\sum\frac{1}{n}$满足$\lim_{n\to\infty}\frac{1}{n}=0$，但仍然发散；**Term $\to0$ is necessary but not sufficient**: for example, the harmonic series $\sum\frac{1}{n}$ has term limit $0$ but still diverges.

#### **一句话总结 / One-Sentence Summary**

*   判断$\sum a_n$是否收敛时，可以按“发散判别法$\rightarrow$比较判别法$\rightarrow$极限比较判别法$\rightarrow$比值判别法$\rightarrow$积分判别法”的顺序快速筛选；**To test whether $\sum a_n$ converges**, a practical order is divergence test $\rightarrow$ comparison test $\rightarrow$ limit comparison test $\rightarrow$ ratio test $\rightarrow$ integral test.
